# FastWAM[[fastwam]]

FastWAM 是一個用於機器人控制的世界動作模型（World Action Model）策略（policy）。LeRobot 的整合透過標準的策略 API 提供 FastWAM，因此可以用 `policy.type=fastwam` 設定、以 `lerobot-train` 訓練，並透過 LeRobot 的預訓練策略介面載入。

## 模型概覽[[model-overview]]

FastWAM 在訓練時保留影片建模，但推論時改為直接預測動作，而不是反覆生成未來的觀測。這個 LeRobot 策略包裝了 FastWAM 的動作模型，將 LeRobot 的批次轉換成 FastWAM 的訓練樣本，並提供標準的處理器管線，負責正規化與動作的後處理。

這個實作預設會從 `Wan-AI/Wan2.2-TI2V-5B` 初始化視覺世界模型（world model）的元件，並預測形狀為 `[batch, action_horizon, action_dim]` 的動作區塊（action chunk）。

### LeRobot 整合涵蓋的範圍[[what-the-lerobot-integration-covers]]

- 透過 LeRobot 使用標準的 `policy.type=fastwam` 設定
- 影像、狀態、動作與語言任務的批次轉換
- 透過 `select_action` 與 `predict_action_chunk` 推論動作區塊
- 透過 LeRobot 的策略 API 儲存／載入檢查點（checkpoint）
- 可設定的 LIBERO 夾爪動作後處理

## 安裝需求[[installation-requirements]]

從原始碼安裝 LeRobot，再安裝 FastWAM 的相依套件：

```bash
pip install -e ".[fastwam]"
```

這會安裝 `pyproject.toml` 中 FastWAM 策略的額外套件：`transformers`、
`diffusers`、`ftfy` 與 `regex`，以及 LeRobot 的基本相依套件。

若要在 LIBERO 上評估，也請安裝該基準測試的相依套件：

```bash
pip install -e ".[fastwam,libero]"
```

這會同時安裝兩個額外套件。除了上述的 FastWAM 相依套件之外，
`libero` 額外套件還會安裝 LeRobot 資料集的相依套件、Linux 上的 `hf-libero`，以及
`scipy`。

FastWAM 使用 Wan2.2 TI2V 作為骨幹網路（backbone）。預設的模型 id 為：

```python
policy.model_id=Wan-AI/Wan2.2-TI2V-5B
```

## 資料需求[[data-requirements]]

FastWAM 需要一個具備以下條件的 LeRobot 資料集：

- 一個或多個視覺觀測，寬度串接起來等於 `policy.image_size[1]`
- 當 `policy.proprio_dim` 不為 `None` 時的 `observation.state`
- `action`
- 透過資料集的任務欄位提供的語言任務指令，或預先計算好的 `context` 與 `context_mask` 張量

預設的視覺設定是一個名為 `observation.images.image`、形狀為 `(3, 224, 448)` 的影像特徵。若資料集使用兩台相機，請設定 `policy.input_features`，讓它們的高度都是 `224`，寬度加總為 `448`。

## 使用方式[[usage]]

使用以下指令建立新的 FastWAM 策略：

```bash
lerobot-train \
  --dataset.repo_id=your-org/your-dataset \
  --policy.type=fastwam \
  --policy.action_dim=7 \
  --policy.proprio_dim=8 \
  --policy.action_horizon=32 \
  --policy.n_action_steps=10 \
  --policy.image_size='[224,448]' \
  --output_dir=./outputs/fastwam_training \
  --job_name=fastwam_training \
  --steps=300000 \
  --batch_size=8 \
  --policy.device=cuda
```

使用以下指令，在 LIBERO-10 上評估既有的 LeRobot 格式檢查點：

```bash
lerobot-eval \
  --policy.path=ZibinDong/fastwam_libero_uncond_2cam224 \
  --policy.device=cuda \
  --policy.dtype=float32 \
  --policy.n_action_steps=10 \
  --env.type=libero \
  --env.task=libero_10 \
  --env.observation_height=224 \
  --env.observation_width=224 \
  --eval.batch_size=1 \
  --eval.n_episodes=50 \
  --seed=0 \
  --env.episode_length=600
```

對於 `libero_goal`、`libero_spatial` 與 `libero_object`，請使用
`--env.episode_length=300`。

若要在真實機器人上進行 rollout，請使用相同的檢查點路徑：

```bash
lerobot-rollout \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyACM0 \
  --policy.path=your-org/fastwam-real-robot
```

## 設定注意事項[[configuration-notes]]

### 影像特徵[[image-features]]

`policy.image_size` 是串接後的 FastWAM 影像張量大小，格式為 `(height, width)`。每個設定的影像特徵都必須是 `(3, height, camera_width)` 的形狀，且所有相機的寬度加總必須等於設定的寬度。

### 動作分塊[[action-chunking]]

`policy.action_horizon` 控制訓練時要監督、推論時要預測的未來動作數量。`policy.n_action_steps` 控制策略在預測新的區塊之前，要先執行完多少個動作。`policy.n_action_steps` 必須小於或等於 `policy.action_horizon`。

### Wan 元件[[wan-components]]

FastWAM 會從設定的 Wan 模型目錄或 Hugging Face Hub 的模型 id，載入 Wan VAE、video DiT、文字編碼器與 tokenizer。以 `save_pretrained` 儲存的 LeRobot 格式 FastWAM 檢查點，也會一併複製 `from_pretrained` 所需的本機 Wan 元件檔案。

### 注意力後端[[attention-backend]]

FastWAM 的 DiT 的所有注意力運算都使用 PyTorch 的 `scaled_dot_product_attention`（SDPA），**不會**使用 FlashAttention：它的 Mixture-of-Transformers（MoT）路由需要任意的布林 `[query, key]` 注意力遮罩，而 FlashAttention 的 varlen API 無法表達這種遮罩。因此，安裝 `flash-attn` 套件對 FastWAM 不會有任何影響。（請注意，SDPA 內部仍可能選用 PyTorch 自己的 flash／memory-efficient／math kernel，這與 `flash-attn` 套件無關。）

### 編譯後的動作推論[[compiled-action-inference]]

FastWAM 可以編譯影片預填（prefill）與快取的動作去雜訊運算圖，減少重複推論步驟中 Python 與 CUDA kernel 啟動的額外負擔：

```bash
--policy.compile_action_infer=true
```

這個選項預設為停用。第一次預測動作時，會為目前的輸入形狀編譯運算圖，因此速度較慢；之後形狀相同的預測就會重複使用它。形狀改變時可能會重新編譯。在不支援的 PyTorch 或加速器設定上，仍然可以使用 eager 模式。

### LIBERO 動作切換[[libero-action-toggle]]

FastWAM 的 LIBERO 檢查點預設使用 `policy.toggle_action_dimensions=[-1]`，
以符合原始 FastWAM 評估流程所採用的夾爪
動作慣例：

```bash
--policy.toggle_action_dimensions='[-1]'
```

## 結果[[results]]

使用 [`ZibinDong/fastwam_libero_uncond_2cam224`](https://huggingface.co/ZibinDong/fastwam_libero_uncond_2cam224) 在 LIBERO 上評估：

| 套件           |    成功率 | n_episodes |
| -------------- | --------: | ---------: |
| libero_spatial |     97.6% |        500 |
| libero_object  |     99.0% |        500 |
| libero_goal    |     95.0% |        500 |
| libero_10      |     94.0% |        500 |
| **平均**       | **96.4%** |       2000 |

重現方式：`lerobot-eval --policy.path=ZibinDong/fastwam_libero_uncond_2cam224 --policy.device=cuda --policy.dtype=float32 --policy.n_action_steps=10 --env.type=libero --env.task=libero_spatial --env.observation_height=256 --env.observation_width=256 --eval.batch_size=1 --eval.n_episodes=50 --seed=0 --env.episode_length=300`（1x H20 140 GB）。
