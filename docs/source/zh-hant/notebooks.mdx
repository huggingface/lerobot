# 🤗 LeRobot Notebooks[[lerobot-notebooks]]

本儲存庫包含 LeRobot 的範例 notebook，示範如何使用標準化的策略（policy），在真實或模擬資料集上訓練策略。

---

### 訓練 ACT[[training-act]]

[ACT](https://huggingface.co/papers/2304.13705)（Action Chunking Transformer）是一種以 transformer 為基礎、用於模仿學習（imitation learning）的策略架構，會處理機器人狀態與相機輸入，產生流暢且分塊（chunked）的動作序列。

我們提供一個可直接執行的 Google Colab notebook，協助你使用 Hugging Face Hub 上的資料集訓練 ACT 策略，並可選擇將記錄傳送到 Weights & Biases。

| Notebook                                                                                                | Colab                                                                                                                                                                             |
| :------------------------------------------------------------------------------------------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Train ACT with LeRobot](https://github.com/huggingface/notebooks/blob/main/lerobot/training-act.ipynb) | [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/huggingface/notebooks/blob/main/lerobot/training-act.ipynb) |

100k 步的預期訓練時間：在 NVIDIA A100 GPU 上、批次大小為 `64` 時約 1.5 小時。

### 訓練 SmolVLA[[training-smolvla]]

[SmolVLA](https://huggingface.co/papers/2506.01844) 是一個小巧但高效的視覺-語言-動作模型（vision-language-action model），參數量僅 450 M，由 Hugging Face 開發。

我們提供一個可直接執行的 Google Colab notebook，協助你使用 Hugging Face Hub 上的資料集訓練 SmolVLA 策略，並可選擇將記錄傳送到 Weights & Biases。

| Notebook                                                                                                        | Colab                                                                                                                                                                                 |
| :-------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Train SmolVLA with LeRobot](https://github.com/huggingface/notebooks/blob/main/lerobot/training-smolvla.ipynb) | [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/huggingface/notebooks/blob/main/lerobot/training-smolvla.ipynb) |

20k 步的預期訓練時間：在 NVIDIA A100 GPU 上、批次大小為 `64` 時約 5 小時。
