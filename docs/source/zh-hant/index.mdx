**用於真實世界機器人的最先進機器學習技術**

🤗 LeRobot 提供與硬體無關的原生 Python 介面，用於控制真實機器人——從 SO-ARM101 這類平價手臂到完整的人形機器人。此外還提供錄製、儲存與分享其所產生資料集的工具。每個資料集都採用標準化的 **LeRobotDataset** 格式（同步的影片 + 動作／狀態資料），並可直接從 [Hugging Face Hub](https://huggingface.co/lerobot) 串流。

🤗 在這些資料之上，LeRobot 實作了最先進的策略（state-of-the-art policies）——從 ACT 這類輕量的模仿學習模型，到 π₀ 與 SmolVLA 這類大型視覺－語言－動作模型（vision-language-action models）——全都只需同樣的幾個 CLI 指令，即可訓練、分享與部署。

目標：降低機器人技術的入門障礙，讓所有人都能為共享的資料集與預訓練模型做出貢獻，並從中受益。

## 運作方式[[how-it-works]]

**遙操作 → 錄製 → 訓練 → 部署**

1. **遙操作**——自行控制機器人（使用主臂、鍵盤或手機），讓它能從你的動作中學習。
2. **錄製**——每次示範都會儲存為資料集：同步的相機影片（synchronized camera video）加上你所採取的動作。
3. **訓練**——策略（policy，即將控制機器人的神經網路）會學習模仿你的示範。
4. **部署**——在機器人上執行訓練好的策略，看著它自行完成任務。

## 常見問題[[common-problems]]

遇到問題了嗎？以下是幾個最常見的情況：

- **相機畫面模糊或無法使用**——光線比解析度更重要。請參閱[相機](./cameras)指南。
- **建置或安裝錯誤**（`cmake`、`ffmpeg`、CUDA）——請參閱[安裝指南](./installation#troubleshooting)的疑難排解章節。
- **不確定哪個策略適合你的 GPU**——請查看[運算與硬體指南](./hardware_guide)。
- **還是卡住了嗎？** 在 [Discord](https://discord.gg/s3KuuzsPFb) 上提問——社群（以及 LeRobot 團隊）隨時樂意協助。
