## 訂購並組裝零件[[order-and-assemble-the-parts]]

首先，請依照官方組裝指南組裝 OMX 硬體。

OMX 組裝指南：https://ai.robotis.com/omx/assembly_guide_omx.html

OMX 機器人出廠時就已經設定好。馬達 ID、通訊參數與關節偏移量都已完成設定，因此使用 LeRobot 之前，不需要再額外設定馬達或進行校正。

## 安裝 LeRobot 🤗[[install-lerobot]]

若要安裝 LeRobot，請依照我們的[安裝指南](./installation)操作。

除了這些說明之外，你還需要安裝 Dynamixel 馬達支援：

```bash
pip install -e ".[dynamixel]"
```

## 連接機器人[[connect-the-robot]]

若要找出每個匯流排伺服馬達轉接器的連接埠，請執行這個腳本：

```bash
lerobot-find-port
```

執行這個指令後，依提示從主臂或從臂其中之一拔掉 USB 線，再按下 Enter。輸出會顯示「The port of this MotorsBus is [port]」，這就是被拔掉的那支手臂的連接埠。對另一支手臂重複相同步驟，就能找出兩個連接埠。

<hfoptions id="find_port">
<hfoption id="Mac">

macOS 上的範例輸出：

```
Finding all available ports for the MotorBus.
['/dev/tty.usbmodem575E0032081', '/dev/tty.usbmodem575E0031751']
Remove the USB cable from your MotorsBus and press Enter when done.

[...Disconnect corresponding leader or follower arm and press Enter...]

The port of this MotorsBus is /dev/tty.usbmodem575E0032081
Reconnect the USB cable.
```

其中找到的連接埠為 `/dev/tty.usbmodem575E0032081`，對應到你的主臂或從臂。

</hfoption>
<hfoption id="Linux">

在 Linux 上，強烈建議使用 udev 規則，為 OMX 主臂與從臂指定固定且容易辨識的裝置名稱。這樣可以避免在機器人拔除、重新插上或系統重新開機時，ttyACM0、ttyACM1 這類裝置名稱跟著改變的問題。

#### 1. 找出你的裝置序號[[1-find-your-device-serial-numbers]]

你應該已經用 `lerobot-find-port` 取得主臂與從臂的連接埠編號，例如 ../../ttyACM?。你可以用 `ls -l /dev/serial/by-id/` 指令，將這些結果與序號對應起來。
若要建立 udev 規則，你需要每個 OMX 裝置獨一無二的序號。最簡單的方式，是列出以下路徑底下的裝置：

```bash
ls -l /dev/serial/by-id/
```

你會看到類似以下的輸出：

```bash
usb-ROBOTIS_OpenRB-150_228BDD7B503059384C2E3120FF0A2B19-if00 -> ../../ttyACM0
usb-ROBOTIS_OpenRB-150_67E1ED68503059384C2E3120FF092234-if00 -> ../../ttyACM1
```

每一行中，序號就是 `usb-ROBOTIS_OpenRB-150_` 之後、`-if00` 之前的那一長串字串。

從臂序號：`228BDD7B503059384C2E3120FF0A2B19`

主臂序號：`67E1ED68503059384C2E3120FF092234`

#### 2. 建立 udev 規則[[2-create-the-udev-rule]]

建立一個新的 udev 規則檔：

```bash
sudo nano /etc/udev/rules.d/99-omx.rules
```

貼上以下內容，並將序號換成你在上面找到的值：

```bash
SUBSYSTEM=="tty", ATTRS{idVendor}=="0403", ATTRS{serial}=="228BDD7B503059384C2E3120FF0A2B19", SYMLINK+="omx_follower"
SUBSYSTEM=="tty", ATTRS{idVendor}=="0403", ATTRS{serial}=="67E1ED68503059384C2E3120FF092234", SYMLINK+="omx_leader"
```

儲存檔案，並重新載入 udev 規則：

```bash
sudo udevadm control --reload-rules
sudo udevadm trigger
```

接著將兩個裝置各拔除再重新插上一次。

#### 3. 驗證符號連結[[3-verify-the-symlinks]]

確認固定的裝置名稱已經存在：

```bash
ls -l /dev/omx_follower /dev/omx_leader
```

你應該會看到它們指向 ttyACM\* 裝置：

```bash
/dev/omx_follower -> ttyACM*
/dev/omx_leader   -> ttyACM*
```

這些名稱在重新開機與重新連接之後都會保持不變。

</hfoption>
</hfoptions>

## 遙操作[[teleoperate]]

確認正確的連接埠之後，就可以直接用主臂遙操作從臂。

<hfoptions id="teleoperate">
<hfoption id="Mac">

### 不使用相機遙操作[[teleoperate-without-camera]]

```bash
lerobot-teleoperate \
  --robot.type=omx_follower \
  --robot.port=<your_follower_port> \
  --robot.id=omx_follower_arm \
  --teleop.type=omx_leader \
  --teleop.port=<your_leader_port> \
  --teleop.id=omx_leader_arm
```

遙操作期間，從臂會即時跟著主臂做出相同的動作。由於 OMX 已預先設定好，不需要任何校正步驟，就能立刻開始遙操作。

### 使用相機遙操作[[teleoperate-with-camera]]

你也可以為從臂提供相機設定，在遙操作期間啟用相機輸入。

```bash
lerobot-teleoperate \
  --robot.type=omx_follower \
  --robot.port=<your_follower_port> \
  --robot.id=omx_follower_arm \
  --robot.cameras="{front: {type: opencv, index_or_path: '/dev/video0', width: 640, height: 480, fps: 30}}" \
  --teleop.type=omx_leader \
  --teleop.port=<your_leader_port> \
  --teleop.id=omx_leader_arm \
  --display_data=true
```

啟用相機後，相機畫面會即時顯示，並與機器人狀態（state）同步。這樣的設定很適合用來進行視覺監控，之後也能沿用於錄製示範與模仿學習。

</hfoption>
