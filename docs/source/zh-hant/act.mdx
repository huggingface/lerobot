# ACT (Action Chunking with Transformers)[[act-action-chunking-with-transformers]]

ACT 是一個**輕量且高效的模仿學習（imitation learning）策略**，特別適合精細的操作任務。由於訓練速度快、運算需求低且表現出色，它是**我們推薦你剛開始使用 LeRobot 時的第一個模型**。

## 模型概覽[[model-overview]]

Action Chunking with Transformers（ACT）由 Zhao 等人在論文 [Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware](https://arxiv.org/abs/2304.13705) 中提出。這個策略（policy）的設計目標，是以平價的硬體和極少量的示範資料，完成精確且接觸頻繁的操作任務。

### 為什麼 ACT 非常適合初學者[[why-act-is-great-for-beginners]]

ACT 是很好的入門選擇，原因如下：

- **訓練快速**：在單張 GPU 上幾小時就能訓練完成
- **輕量**：只有約 8,000 萬個參數，有效率又容易上手
- **資料效率高**：通常只需要 50 筆示範，就能達到很高的成功率

### 架構[[architecture]]

ACT 採用以 Transformer 為基礎的架構，包含三個主要部分：

1. **視覺骨幹網路（vision backbone）**：以 ResNet-18 處理來自多個相機視角的影像
2. **Transformer 編碼器**：整合相機特徵、關節位置，以及學習到的潛在變數
3. **Transformer 解碼器**：使用交叉注意力（cross-attention）產生連貫的動作序列

策略的輸入包括：

- 多張 RGB 影像（例如來自腕部相機、前方／上方相機）
- 機器人目前的關節位置
- 潛在的風格變數 `z`（訓練時學習，推論時設為零）

輸出則是一個包含 `k` 個未來動作序列的區塊（chunk）。

1. 依照我們的[安裝指南](./installation)安裝 LeRobot。

## 訓練 ACT[[training-act]]

ACT 可以直接搭配標準的 LeRobot 訓練流程使用。以下是在你的資料集上訓練 ACT 的完整範例：

```bash
lerobot-train \
  --dataset.repo_id=${HF_USER}/your_dataset \
  --policy.type=act \
  --output_dir=outputs/train/act_your_dataset \
  --job_name=act_your_dataset \
  --policy.device=cuda \
  --wandb.enable=true \
  --policy.repo_id=${HF_USER}/act_policy
```

### 訓練技巧[[training-tips]]

1. **先用預設值**：ACT 的預設超參數對大多數任務都很適用
2. **訓練時間**：在單張 GPU 上訓練 100k 步，大約需要幾小時
3. **批次大小**：先從批次大小 8 開始，再依你的 GPU 記憶體調整

### 使用 Google Colab 訓練[[train-using-google-colab]]

如果你的電腦沒有強大的 GPU，可以依照 [ACT 訓練 notebook](./notebooks#training-act)，使用 Google Colab 訓練模型。

## 評估 ACT[[evaluating-act]]

訓練完成後，可以使用 `lerobot-rollout` 指令搭配訓練好的策略來評估 ACT。這會執行推論並錄下評估的回合（episode）：

```bash
lerobot-rollout \
  --strategy.type=base \
  --policy.path=${HF_USER}/act_policy \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyACM0 \
  --robot.cameras="{ front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}}" \
  --display_data=true \
  --task="Your task description" \ # ACT 可省略
  --duration=60
```
