EarthRover Mini Plus 是一款完全開源的移動機器人，透過 Frodobots SDK 經由雲端連線。你可以用它控制機器人，並錄製資料集來訓練 AI 模型。

## 你需要準備的東西[[what-you-need]]

### 硬體[[hardware]]

- EarthRover Mini 機器人
- 安裝了 Python 3.12 或更新版本的電腦
- 網際網路連線

### 設定 Frodobots SDK[[setting-up-the-frodobots-sdk]]

機器人需要你的電腦上執行 [Frodobots SDK](https://github.com/frodobots-org/earth-rovers-sdk)。步驟如下：

1. 下載並安裝 SDK：

```bash
git clone https://github.com/frodobots-org/earth-rovers-sdk.git
cd earth-rovers-sdk
pip install -r requirements.txt
```

2. 儲存憑證：

在 .env 檔中寫入 Frodobots 團隊提供的 SDK API 金鑰與 bot 名稱等變數。

```bash
SDK_API_TOKEN=your_sdk_api_token_here
BOT_SLUG=your_bot_slug_here
CHROME_EXECUTABLE_PATH=/path/to/chrome_or_chromium
# 預設值為 MAP_ZOOM_LEVEL=18 https://wiki.openstreetmap.org/wiki/Zoom_levels
MAP_ZOOM_LEVEL=18
MISSION_SLUG=your_mission_slug_here
# 影像品質介於 0.1 與 1.0 之間（預設：0.8）
# 建議：0.8，效能較好
IMAGE_QUALITY=0.8
# 影像格式：jpeg、png 或 webp（預設：png）
# 建議：jpeg，效能較好且頻寬用量較低
IMAGE_FORMAT=jpeg
```

3. 啟動 SDK：

```bash
hypercorn main:app --reload
```

4. 開啟網頁瀏覽器，前往 `http://localhost:8000`，然後點選「Join」

SDK 提供以下功能：

- 前後相機的即時影像

> [!IMPORTANT]
> 必須先啟動 SDK，才能使用機器人。

## 安裝 LeRobot[[install-lerobot]]

請依照我們的[安裝指南](./installation)安裝 LeRobot。

除了基本安裝之外，也請安裝 EarthRover Mini 的硬體相依套件：

```bash
pip install -e ".[hardware]"
```

## 運作原理[[how-it-works]]

機器人透過網際網路通訊：

- **移動命令**：透過 SDK 送出
- **相機影像**：從 SDK 接收
- **機器人資訊**：從 SDK 取得電量、位置、速度

不需要接任何線，一切都透過 SDK 運作。

## 校正[[calibration]]

不需要校正！只要 SDK 在執行，機器人就可以使用。

## 控制機器人[[controlling-the-robot]]

你可以用鍵盤控制機器人，就像用 WASD 鍵玩電玩一樣。

### 鍵盤控制[[keyboard-controls]]

| 按鍵 | 動作             |
| ---- | ---------------- |
| W    | 向前移動         |
| S    | 向後移動         |
| A    | 左轉（同時前進） |
| D    | 右轉（同時前進） |
| Q    | 原地向左旋轉     |
| E    | 原地向右旋轉     |
| X    | 停止所有移動     |
| +/=  | 提高速度         |
| -    | 降低速度         |
| ESC  | 中斷連線         |

### 速度設定[[speed-settings]]

你可以調整機器人的移動速度：

- **前進／後退速度**：預設為全速（1.0）
- **轉向速度**：預設為全速（1.0）
- **調整速度**：使用 +/- 鍵，每次調整 0.1

### 試試看[[try-it-out]]

錄製資料之前，先試著駕駛機器人：

```python
from lerobot.robots.earthrover_mini_plus import EarthRoverMiniPlus, EarthRoverMiniPlusConfig
from lerobot.teleoperators.keyboard import KeyboardRoverTeleop, KeyboardRoverTeleopConfig

# 初始化機器人
robot_config = EarthRoverMiniPlusConfig()
robot = EarthRoverMiniPlus(robot_config)

# 初始化遙操作器
teleop_config = KeyboardRoverTeleopConfig(
    linear_speed=1.0,
    angular_speed=1.0,
    speed_increment=0.1
)
teleop = KeyboardRoverTeleop(teleop_config)

# 連線
robot.connect()
teleop.connect()

# 遙操作（使用鍵盤控制）
try:
    while True:
        action = teleop.get_action()
        robot.send_action(action)
except KeyboardInterrupt:
    pass
finally:
    robot.disconnect()
    teleop.disconnect()
```

> [!TIP]
> 如果你使用 Mac，可能需要授予「終端機」存取鍵盤的權限，才能進行遙操作。請前往「系統偏好設定 > 安全性與隱私 > 輸入監控」，並勾選「終端機」。

## 錄製資料[[recording-data]]

能夠熟練地駕駛機器人之後，就可以開始錄製資料來訓練 AI 模型。系統會記錄：

- **你的操作**：你如何移動機器人（前進、後退、轉向）
- **機器人所見**：
  - 兩台相機的影片
  - 機器人的速度與方向
  - 電量與位置
  - GPS 位置與訊號
  - 其他感測器資料
- **發生的時間**：所有資料的時間戳記

### 設定 Hugging Face[[setting-up-hugging-face]]

我們使用 Hugging Face 在線上儲存你的資料。首先，使用你在 [Hugging Face 設定](https://huggingface.co/settings/tokens)中取得的存取權杖（access token）登入：

```bash
hf auth login --token ${HUGGINGFACE_TOKEN} --add-to-git-credential
```

儲存你的 Hugging Face 使用者名稱：

```bash
HF_USER=$(hf auth whoami | awk -F': *' 'NR==1 {print $2}')
echo $HF_USER
```

### 開始錄製[[start-recording]]

使用標準的錄製指令：

```bash
lerobot-record \
    --robot.type=earthrover_mini_plus \
    --teleop.type=keyboard_rover \
    --dataset.repo_id=your_username/dataset_name \
    --dataset.num_episodes=2 \
    --dataset.fps=10 \
    --dataset.single_task="Navigate around obstacles" \
    --dataset.streaming_encoding=true \
    --dataset.encoder_threads=2 \
    --display_data=true
# 可選：--dataset.rgb_encoder.vcodec=auto
```

將 `your_username/dataset_name` 替換為你的 Hugging Face 使用者名稱與資料集的名稱。

### 儲存的內容[[what-gets-saved]]

你的資料集包含：

**你的動作（2 個特徵）**：

- `linear_velocity`：你向前/向後移動了多少
- `angular_velocity`：你向左/向右轉了多少

**機器人觀測（24 個特徵）**：

- 前方相機影片
- 後方相機影片
- 目前速度
- 電量
- 方向
- GPS（緯度、經度、訊號強度）
- 網路訊號強度
- 震動程度
- 燈光狀態（開/關）
- 加速度計（x、y、z）
- 陀螺儀（x、y、z）
- 磁力計（x、y、z）
- 車輪轉速 RPM（4 個車輪）

### 你的資料會存放在哪裡[[where-your-data-goes]]

在你的電腦上：`~/.cache/huggingface/lerobot/{repo-id}`

錄製完成後，你的資料會自動上傳到你的 Hugging Face 頁面：

```bash
echo https://huggingface.co/datasets/${HF_USER}/earthrover-navigation
```

你的資料集會加上 `LeRobot` 標籤，方便社群找到。
