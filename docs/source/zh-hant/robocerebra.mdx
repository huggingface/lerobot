# RoboCerebra[[robocerebra]]

[RoboCerebra](https://robocerebra.github.io/) 是一個長時程（long-horizon）操作基準測試，用來評估 VLA 的**高階推理、規劃與記憶**能力。每個回合（episode）會串接多個子目標，並搭配與語言對應的中間指令，建構在 LIBERO 的模擬器堆疊（MuJoCo + robosuite，Franka Panda 7 自由度）之上。

- 論文：[RoboCerebra: A Large-scale Benchmark for Long-horizon Robotic Manipulation Evaluation](https://arxiv.org/abs/2506.06677)
- 專案網站：[robocerebra.github.io](https://robocerebra.github.io/)
- 資料集：[`lerobot/robocerebra_unified`](https://huggingface.co/datasets/lerobot/robocerebra_unified)——LeRobot v3.0，6,660 個回合／571,116 個影格，20 fps，1,728 個與語言對應的子任務。
- 預訓練策略：[`lerobot/smolvla_robocerebra`](https://huggingface.co/lerobot/smolvla_robocerebra)

## 可用任務[[available-tasks]]

RoboCerebra 沿用 LIBERO 的模擬器，因此評估時使用的是 LIBERO 的 `libero_10` 長時程套件（suite）：

| 套件      | CLI 名稱    | 任務數 | 說明                                        |
| --------- | ----------- | ------ | ------------------------------------------- |
| LIBERO-10 | `libero_10` | 10     | 在廚房／客廳中串接 3–6 個子目標的長時程任務 |

資料集中的每個 RoboCerebra 回合都切分成多個子任務，各自附有自然語言指令；統一資料集會將這些指令提供為獨立的監督訊號（supervision signal）。

## 安裝[[installation]]

RoboCerebra 是建立在 LIBERO 之上，因此只需要安裝 `libero` 額外套件：

```bash
pip install -e ".[libero]"
```

<Tip>
RoboCerebra 需要 Linux 環境（MuJoCo / robosuite）。訓練或評估前，請先設定渲染後端：

```bash
export MUJOCO_GL=egl  # 適用於無螢幕伺服器（HPC、雲端）
```

</Tip>

## 評估[[evaluation]]

RoboCerebra 的評估使用 LIBERO 的 `libero_10` 套件，並採用 RoboCerebra 的相機命名方式（`image` + `wrist_image`），再額外加一個空相機欄位，讓以三視角訓練的策略能收到預期的輸入格式：

```bash
lerobot-eval \
  --policy.path=lerobot/smolvla_robocerebra \
  --env.type=libero \
  --env.task=libero_10 \
  --env.fps=20 \
  --env.obs_type=pixels_agent_pos \
  --env.observation_height=256 \
  --env.observation_width=256 \
  '--env.camera_name_mapping={"agentview_image": "image", "robot0_eye_in_hand_image": "wrist_image"}' \
  --eval.batch_size=1 \
  --eval.n_episodes=10 \
  --eval.use_async_envs=false \
  --policy.device=cuda \
  '--rename_map={"observation.images.image": "observation.images.camera1", "observation.images.wrist_image": "observation.images.camera2"}' \
  --policy.empty_cameras=1
```

### 建議評估回合數[[recommended-evaluation-episodes]]

為了讓基準測試結果可重現，建議在 `libero_10` 套件中**每個任務評估 10 個回合**（共 100 個），與 RoboCerebra 論文使用的評估方式一致。

## 策略的輸入與輸出[[policy-inputs-and-outputs]]

**觀測：**

- `observation.state`——8 維本體感覺（proprioceptive）狀態（7 個關節位置 + 夾爪）
- `observation.images.image`——第三人稱視角，256×256 HWC uint8
- `observation.images.wrist_image`——腕部相機視角，256×256 HWC uint8

**動作：**

- 在 `Box(-1, 1, shape=(7,))` 中連續控制——末端執行器增量（6D）+ 夾爪（1D）

## 訓練[[training]]

[`lerobot/robocerebra_unified`](https://huggingface.co/datasets/lerobot/robocerebra_unified) 這個統一資料集提供兩個 RGB 串流，以及與語言對應的子任務標註：

| 特徵                             | 形狀          | 說明                  |
| -------------------------------- | ------------- | --------------------- |
| `observation.images.image`       | (256, 256, 3) | 第三人稱視角          |
| `observation.images.wrist_image` | (256, 256, 3) | 腕部相機              |
| `observation.state`              | (8,)          | 關節位置 + 夾爪       |
| `action`                         | (7,)          | 末端執行器增量 + 夾爪 |

在此資料集上微調（fine-tune）SmolVLA base：

```bash
lerobot-train \
  --policy.path=lerobot/smolvla_base \
  --dataset.repo_id=lerobot/robocerebra_unified \
  --env.type=libero \
  --env.task=libero_10 \
  --output_dir=outputs/smolvla_robocerebra
```

## 重現已發表的結果[[reproducing-published-results]]

已釋出的檢查點（checkpoint）[`lerobot/smolvla_robocerebra`](https://huggingface.co/lerobot/smolvla_robocerebra) 是以 `lerobot/robocerebra_unified` 訓練，並使用[評估](#evaluation)章節中的指令進行評估。每個修改到此基準測試的 PR，CI 都會以 `--eval.n_episodes=1` 執行相同的指令，作為冒煙測試（smoke test）。
