# VLABench[[vlabench]]

[VLABench](https://github.com/OpenMOSS/VLABench) 是一個大規模基準測試，用來評估**以語言為條件、需要長時程（long-horizon）推理的機器人操作**。上游套件涵蓋 100 個任務類別、超過 2,000 個物件，並從六個面向評估機器人的智慧：網格與紋理理解、空間推理、世界知識遷移、語意指令理解、物理定律理解，以及長時程規劃。它以 MuJoCo / dm_control 建構，使用 Franka Panda 7 自由度機械臂。LeRobot 透過 `--env.task` 開放了其中 **43 個任務**（21 個 primitive 任務 + 22 個 composite 任務，詳見下方的[可用任務](#available-tasks)）。

- 論文：[VLABench: A Large-Scale Benchmark for Language-Conditioned Robotics Manipulation with Long-Horizon Reasoning](https://arxiv.org/abs/2412.18194)
- GitHub：[OpenMOSS/VLABench](https://github.com/OpenMOSS/VLABench)
- 專案網站：[vlabench.github.io](https://vlabench.github.io)
- 預訓練策略：[`lerobot/smolvla_vlabench`](https://huggingface.co/lerobot/smolvla_vlabench)

## 可用任務[[available-tasks]]

VLABench 提供兩個任務套件（suite），在 LeRobot 的 `--env.task` 中共涵蓋 **43 個任務類別**：

| 套件              | CLI 名稱    | 任務數 | 說明                                         |
| ----------------- | ----------- | ------ | -------------------------------------------- |
| 基本（primitive） | `primitive` | 21     | 單一或少量技能的組合（選取、插入、物理問答） |
| 組合（composite） | `composite` | 22     | 多步推理與長時程規劃（烹飪、重新整理）       |

**基本任務：** `select_fruit`、`select_toy`、`select_chemistry_tube`、`add_condiment`、`select_book`、`select_painting`、`select_drink`、`insert_flower`、`select_billiards`、`select_ingredient`、`select_mahjong`、`select_poker`，以及物理推理任務（`density_qa`、`friction_qa`、`magnetism_qa`、`reflection_qa`、`simple_cuestick_usage`、`simple_seesaw_usage`、`sound_speed_qa`、`thermal_expansion_qa`、`weight_qa`）。

**組合任務：** `cluster_billiards`、`cluster_book`、`cluster_drink`、`cluster_toy`、`cook_dishes`、`cool_drink`、`find_unseen_object`、`get_coffee`、`hammer_nail`、`heat_food`、`make_juice`、`play_mahjong`、`play_math_game`、`play_poker`、`play_snooker`、`rearrange_book`、`rearrange_chemistry_tube`、`set_dining_table`、`set_study_table`、`store_food`、`take_chemistry_experiment`、`use_seesaw_complex`。

`--env.task` 接受三種格式：

- 單一任務名稱（`select_fruit`）
- 以逗號分隔的清單（`select_fruit,heat_food`）
- 套件的捷徑名稱（`primitive`、`composite` 或 `primitive,composite`）

## 安裝[[installation]]

VLABench **沒有發布在 PyPI 上**——唯一的取得管道是 [OpenMOSS/VLABench](https://github.com/OpenMOSS/VLABench) GitHub 儲存庫——因此 LeRobot 沒有提供 `vlabench` 額外套件。請手動 clone 並以可編輯模式安裝，同時安裝 VLABench 所需的特定版本 MuJoCo / dm_control，再下載網格（mesh）素材：

```bash
# 在完成標準的 LeRobot 安裝步驟之後。

git clone https://github.com/OpenMOSS/VLABench.git ~/VLABench
git clone https://github.com/motion-planning/rrt-algorithms.git ~/rrt-algorithms
pip install -e ~/VLABench -e ~/rrt-algorithms
pip install "mujoco==3.2.2" "dm-control==1.0.22" \
            open3d colorlog scikit-learn openai gdown

python ~/VLABench/scripts/download_assets.py
```

<Tip>
VLABench 需要 Linux（`sys_platform == 'linux'`）與 Python 3.10+。執行前，請先設定 MuJoCo 的渲染後端：

```bash
export MUJOCO_GL=egl  # 適用於無頭伺服器（HPC、雲端）
```

</Tip>

## 評估[[evaluation]]

以下所有評估指令都與 CI 執行的指令相同（請參閱 `.github/workflows/benchmark_tests.yml`）。`--rename_map` 引數會將 VLABench 的 `image` / `second_image` / `wrist_image` 相機鍵名，對應到已發布的 `smolvla_vlabench` 策略訓練時使用的三相機（`camera1` / `camera2` / `camera3`）輸入格式。

### 單任務評估（建議用於快速迭代）[[single-task-evaluation-recommended-for-quick-iteration]]

```bash
lerobot-eval \
  --policy.path=lerobot/smolvla_vlabench \
  --env.type=vlabench \
  --env.task=select_fruit \
  --eval.batch_size=1 \
  --eval.n_episodes=10 \
  --eval.use_async_envs=false \
  --policy.device=cuda \
  '--rename_map={"observation.images.image": "observation.images.camera1", "observation.images.second_image": "observation.images.camera2", "observation.images.wrist_image": "observation.images.camera3"}'
```

### 多任務評估[[multi-task-evaluation]]

傳入以逗號分隔的任務清單：

```bash
lerobot-eval \
  --policy.path=lerobot/smolvla_vlabench \
  --env.type=vlabench \
  --env.task=select_fruit,select_toy,add_condiment,heat_food \
  --eval.batch_size=1 \
  --eval.n_episodes=10 \
  --eval.use_async_envs=false \
  --policy.device=cuda \
  '--rename_map={"observation.images.image": "observation.images.camera1", "observation.images.second_image": "observation.images.camera2", "observation.images.wrist_image": "observation.images.camera3"}'
```

### 全套件評估[[suite-wide-evaluation]]

執行整個套件（全部 21 個 primitive 任務，或全部 22 個 composite 任務）：

```bash
lerobot-eval \
  --policy.path=lerobot/smolvla_vlabench \
  --env.type=vlabench \
  --env.task=primitive \
  --eval.batch_size=1 \
  --eval.n_episodes=10 \
  --eval.use_async_envs=false \
  --policy.device=cuda \
  --env.max_parallel_tasks=1 \
  '--rename_map={"observation.images.image": "observation.images.camera1", "observation.images.second_image": "observation.images.camera2", "observation.images.wrist_image": "observation.images.camera3"}'
```

或同時執行兩個套件：

```bash
lerobot-eval \
  --policy.path=lerobot/smolvla_vlabench \
  --env.type=vlabench \
  --env.task=primitive,composite \
  --eval.batch_size=1 \
  --eval.n_episodes=10 \
  --eval.use_async_envs=false \
  --policy.device=cuda \
  --env.max_parallel_tasks=1 \
  '--rename_map={"observation.images.image": "observation.images.camera1", "observation.images.second_image": "observation.images.camera2", "observation.images.wrist_image": "observation.images.camera3"}'
```

### 建議評估回合數[[recommended-evaluation-episodes]]

為了讓基準測試結果可重現，建議**每個任務評估 10 個回合（episode）**（完整的 primitive 套件共 210 個回合，composite 共 220 個），與 VLABench 論文的評估方式一致。

## 策略的輸入與輸出[[policy-inputs-and-outputs]]

**觀測：**

- `observation.state`——7 維末端執行器狀態（位置 xyz + 歐拉角 xyz + 夾爪）
- `observation.images.image`——前方相機，480×480 HWC uint8
- `observation.images.second_image`——第二台相機，480×480 HWC uint8
- `observation.images.wrist_image`——腕部相機，480×480 HWC uint8

**動作：**

- 在 `Box(-1, 1, shape=(7,))` 中連續控制——3D 位置 + 3D 歐拉角朝向 + 1D 夾爪。

## 訓練[[training]]

### 資料集[[datasets]]

Hub 上已收集好的 LeRobot 格式 VLABench 資料集：

- [`VLABench/vlabench_primitive_ft_lerobot_video`](https://huggingface.co/datasets/VLABench/vlabench_primitive_ft_lerobot_video)——5,000 個回合，128 個任務，480×480 影像。
- [`VLABench/vlabench_composite_ft_lerobot_video`](https://huggingface.co/datasets/VLABench/vlabench_composite_ft_lerobot_video)——5,977 個回合，167 個任務，224×224 影像。

### 訓練指令範例[[example-training-command]]

在 primitive 套件上微調（fine-tune）SmolVLA base：

```bash
lerobot-train \
  --policy.type=smolvla \
  --policy.repo_id=${HF_USER}/smolvla_vlabench_primitive \
  --policy.load_vlm_weights=true \
  --policy.push_to_hub=true \
  --dataset.repo_id=VLABench/vlabench_primitive_ft_lerobot_video \
  --env.type=vlabench \
  --env.task=select_fruit \
  --output_dir=./outputs/smolvla_vlabench_primitive \
  --steps=100000 \
  --batch_size=4 \
  --env_eval_freq=5000 \
  --eval.batch_size=1 \
  --eval.n_episodes=1 \
  --save_freq=10000
```

## 重現已發表的結果[[reproducing-published-results]]

已發布的檢查點（checkpoint）[`lerobot/smolvla_vlabench`](https://huggingface.co/lerobot/smolvla_vlabench) 是以上述 primitive 套件的資料集訓練，並使用[單一任務](#single-task-evaluation-recommended-for-quick-iteration)／[整個套件](#suite-wide-evaluation)的指令評估。每個修改到此基準測試的 PR，CI 都會對 10 個 primitive 任務執行冒煙評估（smoke eval，每個任務一個回合）。
