# 機器人（Robots）[[robots]]

LeRobot 中的每個機器人都實作了 [`Robot`] 介面（interface）：連線、讀取觀測、送出動作、中斷連線。針對此介面撰寫的策略或錄製腳本，不需修改就能用於任何支援的手臂。

本頁是自動產生的參考文件。接線、校正與首次執行的說明，請從各硬體指南開始，包括 [SO-101](../so101)、[LeKiwi](../lekiwi)、[Hope Jr](../hope_jr)、[Reachy 2](../reachy2)、[OpenArm](../openarm)；完整的端到端流程請參閱[機器人的模仿學習](../il_robots)。若要加入您自己的機器人，請參閱[自備硬體](../integrate_hardware)。
