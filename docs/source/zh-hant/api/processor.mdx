# 處理器（Processors）[[processors]]

處理器是介於機器人、資料集與策略之間的資料轉換層（data transformation layer）。管線（pipeline）是由多個 [`ProcessorStep`] 串接而成；每個步驟都會宣告它如何轉換資料，以及如何轉換特徵契約（feature contract）。

相關概念請參閱[處理器簡介](../introduction_processors)，撰寫步驟請參閱[實作你自己的處理器](../implement_your_own_processor)，管線運作異常時請參閱[除錯你的處理器管線](../debug_processor_pipeline)。
