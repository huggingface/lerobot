# 資料集（Datasets）[[datasets]]

[`LeRobotDataset`] 是所有 LeRobot 腳本讀寫的格式。它能辨識回合邊界（episode-aware），會即時解碼影片形式的觀測，並可推送至 Hugging Face Hub，再原封不動地載入回來。

格式與常見操作請參閱[使用 LeRobotDataset](../lerobot-dataset-v3)，資料集格式遷移請參閱[移植大型資料集](../porting_datasets_v3)，CLI 請參閱[工具](../tools)。
