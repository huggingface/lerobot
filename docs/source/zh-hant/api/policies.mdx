# 策略（Policies）[[policies]]

每個策略都繼承 [`PreTrainedPolicy`]，它結合了 `torch.nn.Module` 與 Hub mixin，因此任何策略都能以相同的兩個呼叫推送到 Hugging Face Hub 或從中載入。

每個策略都有各自的指南，包含訓練方法與結果：[ACT](../act)、[SmolVLA](../smolvla)、[π₀](../pi0)、[π₀.₅](../pi05)，其餘的列在「策略」分類下。若要新增策略，請參閱[新增策略](../bring_your_own_policies)。
