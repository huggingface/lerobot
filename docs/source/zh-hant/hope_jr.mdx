# HopeJR[[hopejr]]

## 事前準備[[prerequisites]]

- [硬體設定](https://github.com/TheRobotStudio/HOPEJr)

## 安裝 LeRobot[[install-lerobot]]

請依照[安裝說明](https://github.com/huggingface/lerobot#installation)安裝 LeRobot。

安裝 LeRobot 以及 HopeJR 的相依套件：

```bash
pip install -e ".[hopejr]"
```

## 裝置設定[[device-configuration]]

開始校正與操作之前，你需要找出每個 HopeJR 元件對應的 USB 連接埠（port）。執行此腳本，找出手臂、手、手套與外骨骼的 USB 連接埠：

```bash
lerobot-find-port
```

這會顯示可用的 USB 連接埠及其對應的裝置。請記下連接埠路徑（例如 `/dev/tty.usbmodem58760433331`、`/dev/tty.usbmodem11301`），之後錄製資料、重播回合（episode）或執行遙操作腳本時，都需要在 `--robot.port` 與 `--teleop.port` 參數中指定它們。

## 步驟 1：校正[[step-1-calibration]]

進行遙操作（teleoperation）之前，需要先校正（calibrate）HopeJR 的四肢。校正檔案會儲存在 `~/.cache/huggingface/lerobot/calibration`

### 1.1 校正機器人手部[[11-calibrate-robot-hand]]

```bash
lerobot-calibrate \
    --robot.type=hope_jr_hand \
    --robot.port=/dev/tty.usbmodem58760432281 \
    --robot.id=blue \
    --robot.side=right
```

執行校正腳本時，會彈出一個校正 GUI。手指關節的名稱如下：

**拇指（thumb）**：

- **CMC**：連接拇指與手掌的基部關節
- **MCP**：指節關節
- **PIP**：第一指節關節
- **DIP**：指尖關節

**食指、中指、無名指與小指**：

- **橈側屈肌（radial flexor）**：將手指基部往拇指的方向移動
- **尺側屈肌（ulnar flexor）**：將手指基部往小指的方向移動
- **PIP/DIP**：彎曲手指的遠端與近端指骨

以上每一項都需要透過 GUI 個別校正。
請注意，尺側與橈側屈肌的範圍大小應該相同（但偏移量不同），才能做出對稱的動作。

### 1.2 校正遙操作器手套[[12-calibrate-teleoperator-glove]]

```bash
lerobot-calibrate \
    --teleop.type=homunculus_glove \
    --teleop.port=/dev/tty.usbmodem11201 \
    --teleop.id=red \
    --teleop.side=right
```

從拇指開始，讓每根手指走完完整的活動範圍。

```
Move thumb through its entire range of motion.
Recording positions. Press ENTER to stop...

-------------------------------------------
NAME      |    MIN |    POS |    MAX
thumb_cmc |   1790 |   1831 |   1853
thumb_mcp |   1497 |   1514 |   1528
thumb_pip |   1466 |   1496 |   1515
thumb_dip |   1463 |   1484 |   1514
```

接著對每根手指重複這個步驟：

```
Move middle through its entire range of motion.
Recording positions. Press ENTER to stop...

-------------------------------------------
NAME                 |    MIN |    POS |    MAX
middle_mcp_abduction |   1598 |   1718 |   1820
middle_mcp_flexion   |   1512 |   1658 |   2136
middle_dip           |   1484 |   1500 |   1547
```

校正完成後，系統會將校正結果儲存到 `/Users/your_username/.cache/huggingface/lerobot/calibration/teleoperators/homunculus_glove/red.json`

### 1.3 校正機器人手臂[[13-calibrate-robot-arm]]

```bash
lerobot-calibrate \
    --robot.type=hope_jr_arm \
    --robot.port=/dev/tty.usbserial-1110 \
    --robot.id=white
```

這會開啟一個校正 GUI，你可以在其中設定每個馬達的範圍限制。手臂的動作分類如下：

- **肩部**：俯仰（pitch）、偏擺（yaw）與滾轉（roll）
- **肘部**：彎曲（flex）
- **腕部**：俯仰、偏擺與滾轉

### 1.4 校正遙操作器外骨骼[[14-calibrate-teleoperator-exoskeleton]]

```bash
lerobot-calibrate \
    --teleop.type=homunculus_arm \
    --teleop.port=/dev/tty.usbmodem11201 \
    --teleop.id=black
```

## 步驟 2：遙操作[[step-2-teleoperation]]

由於 Feetech 中介軟體中的全域變數會互相衝突，手臂與手的遙操作必須在不同的 shell 工作階段中執行：

### 手[[hand]]

```bash
lerobot-teleoperate \
    --robot.type=hope_jr_hand \
    --robot.port=/dev/tty.usbmodem58760432281 \
    --robot.id=blue \
    --robot.side=right \
    --teleop.type=homunculus_glove \
    --teleop.port=/dev/tty.usbmodem11201 \
    --teleop.id=red \
    --teleop.side=right \
    --display_data=true \
    --fps=30
```

### 手臂[[arm]]

```bash
lerobot-teleoperate \
    --robot.type=hope_jr_arm \
    --robot.port=/dev/tty.usbserial-1110 \
    --robot.id=white \
    --teleop.type=homunculus_arm \
    --teleop.port=/dev/tty.usbmodem11201 \
    --teleop.id=black \
    --display_data=true \
    --fps=30
```

## 步驟 3：錄製、重播與訓練[[step-3-record-replay-train]]

使用 Hope-JR 進行錄製、重播與訓練目前仍屬實驗性功能。

### 錄製[[record]]

這個步驟會錄製資料集，範例可以在[這裡](https://huggingface.co/datasets/nepyope/hand_record_test_with_video_data)查看。

```bash
lerobot-record \
    --robot.type=hope_jr_hand \
    --robot.port=/dev/tty.usbmodem58760432281 \
    --robot.id=right \
    --robot.side=right \
    --robot.cameras='{"main": {"type": "opencv", "index_or_path": 0, "width": 640, "height": 480, "fps": 30}}' \
    --teleop.type=homunculus_glove \
    --teleop.port=/dev/tty.usbmodem1201 \
    --teleop.id=right \
    --teleop.side=right \
    --dataset.repo_id=<USER>/hand_record_test_with_video_data \
    --dataset.single_task="Hand recording test with video data" \
    --dataset.num_episodes=1 \
    --dataset.episode_time_s=5 \
    --dataset.push_to_hub=true \
    --dataset.private=true \
    --dataset.streaming_encoding=true \
    --dataset.encoder_threads=2 \
    --display_data=true
# 可選：--dataset.rgb_encoder.vcodec=auto
```

### 重播[[replay]]

```bash
lerobot-replay \
    --robot.type=hope_jr_hand \
    --robot.port=/dev/tty.usbmodem58760432281 \
    --robot.id=right \
    --robot.side=right \
    --dataset.repo_id=<USER>/hand_record_test_with_camera \
    --dataset.episode=0
```

### 訓練[[train]]

```bash
lerobot-train \
  --dataset.repo_id=<USER>/hand_record_test_with_video_data \
  --policy.type=act \
  --output_dir=outputs/train/hopejr_hand \
  --job_name=hopejr \
  --policy.device=mps \
  --wandb.enable=true \
  --policy.repo_id=<USER>/hand_test_policy
```

### 評估[[evaluate]]

這次訓練的執行紀錄可以在[這裡](https://wandb.ai/tino/lerobot/runs/rp0k8zvw?nw=nwusertino)查看，作為範例參考。

```bash
lerobot-record \
  --robot.type=hope_jr_hand \
  --robot.port=/dev/tty.usbmodem58760432281 \
  --robot.id=right \
  --robot.side=right \
  --robot.cameras='{"main": {"type": "opencv", "index_or_path": 0, "width": 640, "height": 480, "fps": 30}}' \
  --display_data=false \
  --dataset.repo_id=<USER>/eval_hopejr \
  --dataset.single_task="Evaluate hopejr hand policy" \
  --dataset.num_episodes=10 \
  --dataset.streaming_encoding=true \
  --dataset.encoder_threads=2 \
  --policy.path=outputs/train/hopejr_hand/checkpoints/last/pretrained_model
# 可選：--dataset.rgb_encoder.vcodec=auto
```
