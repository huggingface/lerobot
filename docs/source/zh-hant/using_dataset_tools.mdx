# 使用資料集工具[[using-dataset-tools]]

本指南說明如何在線上或本機探索 LeRobot 資料集，並介紹 LeRobot 提供的資料集修改與編輯工具。

## 在瀏覽器中探索資料集[[explore-a-dataset-in-the-browser]]

要查看 LeRobot 資料集的內容，最快的方式是使用 [LeRobot Dataset Visualizer](https://huggingface.co/spaces/lerobot/visualize_dataset)。這是一個 Hugging Face Space，不需要安裝任何東西，就能播放 Hub 上的任何 LeRobot 資料集。除非你選擇不上傳，否則用 `lerobot` 錄製的資料集都會推送到 Hub，所以你自己的錄製內容也能在這裡開啟。

## 在本機視覺化資料集[[visualize-a-dataset-locally]]

你也可以使用我們的命令列工具，在本機視覺化資料集中的回合（episode）。

**從 Hugging Face Hub：**

```bash
lerobot-dataset-viz \
    --repo-id lerobot/pusht \
    --episode-index 0
```

若是私有或需要申請存取（gated）的資料集，請先執行 `hf auth login` 進行驗證，或設定
`HF_TOKEN` 環境變數。Hub 用戶端會自動找到這份憑證，
不需要另外傳入 token 引數。

**從本機資料夾：**
加上 `--root` 選項並設定 `--mode local`。例如，要在 `./my_local_data_dir/lerobot/pusht` 中搜尋：

```bash
lerobot-dataset-viz \
    --repo-id lerobot/pusht \
    --root ./my_local_data_dir \
    --mode local \
    --episode-index 0
```

執行後，工具會開啟 `rerun.io`，顯示所選回合的相機串流、機器人狀態與動作。

若要改用 [Foxglove](https://foxglove.dev) 而不是 Rerun，請安裝對應的額外套件並加上 `--display-mode foxglove`。這會啟動一個 WebSocket 伺服器（將 Foxglove app 連線到 `ws://127.0.0.1:8765`），把該回合提供為可拖曳定位的時間軸，讓你播放、暫停與拖曳瀏覽。

若要使用進階功能，例如視覺化儲存在遠端伺服器上的資料集，請執行：

```bash
lerobot-dataset-viz --help
```

## 編輯資料集[[editing-datasets]]

LeRobot 提供以下幾種操作資料集的工具：

1. **刪除回合** - 從資料集中移除特定的回合（episode）
2. **分割資料集** - 將一個資料集切分為多個較小的資料集
3. **合併資料集** - 將多個資料集合併成一個。這些資料集的特徵（feature）必須完全相同，回合會依 `repo_ids` 中指定的順序串接
4. **新增特徵** - 為資料集新增特徵
5. **移除特徵** - 從資料集移除特徵
6. **修改任務** - 變更回合所對應的自然語言任務描述
7. **轉換為影片** - 將以影像儲存的資料集轉換為影片格式，以節省儲存空間（RGB 與深度相機會分別以不同的編碼器編碼）
8. **重新編碼影片** - 以新的編碼器設定，重新編碼既有影片資料集的 RGB 及／或深度串流
9. **顯示資料集資訊** - 顯示資料集的摘要資訊，例如回合數量等

核心實作位於 `lerobot.datasets.dataset_tools`。
`examples/dataset/use_dataset_tools.py` 提供了範例腳本，詳細說明如何使用工具 API。

## 命令列工具：lerobot-edit-dataset[[command-line-tool-lerobot-edit-dataset]]

`lerobot-edit-dataset` 是用來編輯資料集的命令列腳本，可以刪除回合（episode）、分割資料集、合併資料集、新增特徵（feature）、移除特徵，以及將影像資料集轉換為影片格式。

執行 `lerobot-edit-dataset --help`，即可查看每個操作的設定說明。

### 使用範例[[usage-examples]]

#### 刪除回合[[delete-episodes]]

從資料集中移除特定的回合。這適合用來過濾掉不需要的資料。

```bash
# 刪除回合 0、2 與 5（修改原始資料集）
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type delete_episodes \
    --operation.episode_indices "[0, 2, 5]"

# 刪除回合並儲存為新的資料集（保留原始資料集）
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --new_repo_id lerobot/pusht_after_deletion \
    --operation.type delete_episodes \
    --operation.episode_indices "[0, 2, 5]"
```

#### 分割資料集[[split-dataset]]

將一個資料集切分為多個子集。

```bash
# 依比例分割（例如 60% train、20% val、20% test）
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type split \
    --operation.splits '{"train": 0.6, "val": 0.2, "test": 0.2}'

# 依特定的回合索引分割
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type split \
    --operation.splits '{"task1": [0, 1, 2, 3], "task2": [4, 5]}'
```

分割名稱沒有限制，可以自行決定。產生的資料集會以 repo id 加上分割名稱作為後綴儲存，例如 `lerobot/pusht_train`、`lerobot/pusht_task1`、`lerobot/pusht_task2`。

#### 合併資料集[[merge-datasets]]

將多個資料集合併成單一資料集。

```bash
# 將 train 與 validation 分割合併回一個資料集
lerobot-edit-dataset \
    --repo_id lerobot/pusht_merged \
    --operation.type merge \
    --operation.repo_ids "['lerobot/pusht_train', 'lerobot/pusht_val']"
```

#### 移除特徵[[remove-features]]

從資料集移除特徵。

```bash
# 移除一個相機特徵
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type remove_feature \
    --operation.feature_names "['observation.images.top']"
```

#### 修改任務[[modify-tasks]]

變更回合所對應的自然語言任務描述。這適合用來修正錯字、統一用語，或重新標註回合。

> [!WARNING]
> `modify_tasks` 會**就地**（in-place）修改資料集（更新 `meta/tasks.parquet`、資料檔案中的 `task_index` 欄位、回合中繼資料中的 `tasks` 欄位，以及 `meta/info.json` 中的 `total_tasks`）。此操作會忽略 `--new_repo_id` 與 `--new_root` 參數。

```bash
# 為所有回合設定單一任務
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type modify_tasks \
    --operation.new_task "Pick up the cube and place it"

# 為特定回合設定不同的任務
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type modify_tasks \
    --operation.episode_tasks '{"0": "Task A", "1": "Task B", "2": "Task A"}'

# 取代所有出現的既有任務字串
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type modify_tasks \
    --operation.task_replacements '{"Pick up the red cube": "Lift the red cube"}'

# 在一次執行中合併多種模式
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type modify_tasks \
    --operation.new_task "Default task" \
    --operation.task_replacements '{"Pick up the red cube": "Lift the red cube"}' \
    --operation.episode_tasks '{"5": "Special task for episode 5"}'
```

**參數：**

- `new_task`：單一任務字串，作為其他規則未涵蓋之回合的預設任務。
- `episode_tasks`：從回合索引到任務字串的對應。
- `task_replacements`：從既有任務字串到替換字串的對應，會套用到目前任務與某個鍵相符的回合。每個鍵都必須是資料集中已存在的任務。

這些模式可以在同一次執行中搭配使用。每個回合的任務會依下列優先順序決定：

`episode_tasks` > `task_replacements` > `new_task` > 原始任務

`new_task`、`episode_tasks` 與 `task_replacements` 至少要指定其中一個。若某個回合最後沒有任務，會引發錯誤。

#### 轉換為影片[[convert-to-video]]

將以影像儲存的資料集轉換為影片格式，建立一個新的 LeRobotDataset，其中的影像會以影片儲存。這可以降低儲存需求，並提升資料載入效能。新資料集的結構與原始資料集完全相同，只是影像會依 LeRobot 的格式編碼為 MP4 影片。

```bash
# 僅本機：儲存到自訂的輸出目錄（不推送到 hub）
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_image_to_video \
    --operation.output_dir /path/to/output/pusht_video

# 以新的 repo_id 儲存（本機儲存）
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --new_repo_id lerobot/pusht_video \
    --operation.type convert_image_to_video

# 轉換並推送到 Hugging Face Hub
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --new_repo_id lerobot/pusht_video \
    --operation.type convert_image_to_video \
    --push_to_hub true

# 以自訂的影片編解碼器與品質設定進行轉換
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_image_to_video \
    --operation.output_dir outputs/pusht_video \
    --operation.rgb_encoder.vcodec libsvtav1 \
    --operation.rgb_encoder.pix_fmt yuv420p \
    --operation.rgb_encoder.g 2 \
    --operation.rgb_encoder.crf 30

# 轉換包含深度圖（depth map）的資料集，並自訂深度編碼器
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_image_to_video \
    --operation.output_dir outputs/pusht_video \
    --operation.depth_encoder.depth_min 0.01 \
    --operation.depth_encoder.depth_max 10.0 \
    --operation.depth_encoder.use_log true

# 只轉換特定的回合
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_image_to_video \
    --operation.output_dir outputs/pusht_video \
    --operation.episode_indices "[0, 1, 2, 5, 10]"

# 以多個 worker 進行平行處理的轉換
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_image_to_video \
    --operation.output_dir outputs/pusht_video \
    --operation.num_workers 8

# 對於記憶體受限的系統，使用者現在可以指定上限：
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type convert_to_video \
    --operation.max_episodes_per_batch 50 \
    --operation.max_frames_per_batch 10000
```

**參數：**

- `output_dir`：自訂的輸出目錄（可選，預設使用 `new_repo_id` 或 `{repo_id}_video`）
- `rgb_encoder`：套用到 RGB 相機的影片編碼器設定，所有子欄位都可以透過 `--operation.rgb_encoder.<field>` 設定。更多細節請參閱[影片編碼參數](./video_encoding_parameters)。
- `depth_encoder`：套用到深度圖相機（例如 Intel RealSense）的影片編碼器設定。除了標準的編碼器欄位，它還提供深度量化（quantization）的調整項（`depth_min`、`depth_max`、`shift`、`use_log`），可透過 `--operation.depth_encoder.<field>` 設定。這些量化設定會儲存到資料集的中繼資料（metadata）中，以便在載入時將深度反量化回實體單位。詳情請參閱[深度串流](./video_encoding_parameters#depth-streams)章節。
- `episode_indices`：要轉換的回合清單（預設：所有回合）
- `num_workers`：平行處理的 worker 數量（預設：4）

**注意：** 產生的資料集會是一個完整的 LeRobotDataset，所有相機都會以影片形式編碼並存放在 `videos/` 目錄中，parquet 檔案則只包含中繼資料（不含原始影像資料）。深度圖相機會被自動偵測並交給 `depth_encoder` 處理，RGB 相機則使用 `rgb_encoder`。所有回合、統計值與任務都會保留。

#### 重新編碼影片[[re-encode-videos]]

以不同的編碼器設定重新編碼既有影片資料集中的影片，不需要回到原始影格。RGB 影片使用 `rgb_encoder`，深度影片使用 `depth_encoder`。只需提供你想要重新編碼的編碼器；另一種串流會維持不變。

```bash
# 以新設定重新編碼所有 RGB 影片（預設儲存到 lerobot/pusht_reencoded）
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --operation.type reencode_videos \
    --operation.rgb_encoder.vcodec h264 \
    --operation.rgb_encoder.pix_fmt yuv420p \
    --operation.rgb_encoder.crf 23

# 在具有深度圖的資料集中同時重新編碼 RGB 與深度影片
lerobot-edit-dataset \
    --repo_id lerobot/pusht_depth \
    --operation.type reencode_videos \
    --operation.rgb_encoder.vcodec h264 \
    --operation.depth_encoder.crf 50
```

**參數：**

- `rgb_encoder`：套用到每個 RGB 影片的編碼器設定。省略即可跳過 RGB 影片的重新編碼。
- `depth_encoder`：套用到每個深度影片的編碼器設定。省略即可跳過深度影片的重新編碼。
- `num_workers`：平行處理的 worker 數量。

> [!NOTE]
> 重新編碼深度影片時，既有的深度量化參數（`depth_min`、`depth_max`、`shift`、`use_log`）與 `is_depth_map` 旗標都會**保留**。重新編碼只會改變已儲存串流的編解碼器（codec）與品質，不會改變載入時反量化深度的方式。

### 顯示資料集的資訊[[show-the-information-of-datasets]]

顯示資料集的資訊，例如回合數、影格數、檔案大小等。
不會對資料集做任何變更

```bash

# 顯示資料集資訊而不含特徵細節
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type info \

# 顯示含特徵細節的資料集資訊
lerobot-edit-dataset \
    --repo_id lerobot/pusht_image \
    --operation.type info \
    --operation.show_features true

```

**參數：**

- `parameters`：控制顯示資料集資訊時是否包含特徵細節的旗標（預設 = false）。

### 推送到 Hub[[push-to-hub]]

在任何指令中加上 `--push_to_hub true` 旗標，即可自動將產生的資料集上傳到 Hugging Face Hub：

```bash
lerobot-edit-dataset \
    --repo_id lerobot/pusht \
    --new_repo_id lerobot/pusht_after_deletion \
    --operation.type delete_episodes \
    --operation.episode_indices "[0, 2, 5]" \
    --push_to_hub true
```

另外還有一個為資料集新增特徵的工具，目前尚未納入 `lerobot-edit-dataset`。
