# 第三方機器人與遙操作裝置[[third-party-robots-teleoperators]]

LeRobot 生態系統遠超出官方支援的硬體。拜 LeRobot 的外掛架構所賜，社群已為各式各樣的機械手臂與遙操作裝置建立整合 —— 從工業機械手臂到平價的業餘愛好者平台、VR 頭戴式裝置、觸覺回饋裝置，以及完整的手臂加遙操作裝置套件。本頁展示社群維護的整合，可用於遙操作、資料收集與策略部署。

> [!IMPORTANT]
> 這些專案由第三方開發與維護。請參閱各自的儲存庫以取得安裝說明、硬體需求與支援。

隨插即用外掛會依套件名稱自動探索：LeRobot 會匯入任何已安裝且套件名稱開頭為 `lerobot_robot_` 或 `lerobot_teleoperator_` 的套件。安裝後，可直接從任何 LeRobot 指令引用外掛註冊的 `type`（請參閱其 README —— 它可能與套件名稱不同）：

```bash
pip install lerobot_robot_<name> lerobot_teleoperator_<name>

lerobot-record \
    --robot.type=<robot_name> \
    --teleop.type=<teleoperator_name> \
    --dataset.repo_id=${HF_USER}/my-dataset \
    --dataset.num_episodes=5
```

> [!TIP]
> ⚠️ 標示的是 LeRobot 的分支／擴充專案。它們可能需要自訂設定，而無法在未經修改的安裝環境中運作。所有其他項目皆為隨插即用外掛。
