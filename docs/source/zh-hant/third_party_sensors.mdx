# 第三方相機與感測器[[third-party-cameras-sensors]]

LeRobot 生態系統遠遠超出其原生支援的相機（OpenCV、Intel RealSense、ZMQ、Reachy 2）。拜 LeRobot 的外掛（plugin）架構所賜，社群已打造出隨插即用的相機與感測器整合，從深度相機到視覺式觸覺感測器都有。本頁展示社群維護的相機與感測器整合，可用於遙操作、資料收集與策略部署（policy deployment）。

> [!IMPORTANT]
> 這些專案由第三方開發與維護。請參閱各個儲存庫以取得安裝說明、硬體需求與支援。

隨插即用的外掛會依套件名稱自動被找到：LeRobot 會匯入任何以 `lerobot_camera_` 為前綴的已安裝套件。安裝後，即可在任何 LeRobot 指令中直接參照外掛所註冊的相機 `type`（請參閱其 README——它可能與套件名稱不同）：

```bash
pip install lerobot_camera_<name>

lerobot-record \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.cameras="{ front: {type: <name>, width: 640, height: 480, fps: 30} }" \
    --dataset.repo_id=${HF_USER}/my-dataset \
    --dataset.num_episodes=5
```

## 貢獻[[contributing]]

打造了自己的 LeRobot 相機或感測器整合嗎？將它打包成可安裝的 `lerobot_camera_<name>` 外掛，LeRobot CLI 就會自動找到它。請參閱[整合自己的硬體](./integrate_hardware)指南與[相機](./cameras)參考資料以開始使用，然後與社群分享你的專案！
