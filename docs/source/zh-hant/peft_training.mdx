# 使用 🤗 PEFT 進行參數高效微調[[parameter-efficient-fine-tuning-with-peft]]

[🤗 PEFT](https://github.com/huggingface/peft)（Parameter-Efficient Fine-Tuning）是一個函式庫，能有效率地讓大型預訓練模型，
例如預訓練策略（SmolVLA、π₀ 等），適應新的任務，而不必訓練模型的
所有參數，同時仍能達到相當的效能。

安裝可選套件 `lerobot[peft]`，即可啟用 PEFT 支援。

若要了解所有可用的適應方法，請參閱 [🤗 PEFT 文件](https://huggingface.co/docs/peft/index)。

## 訓練 SmolVLA[[training-smolvla]]

本節將示範如何使用 PEFT，在 libero 資料集上訓練預訓練的 SmolVLA 策略。
為了簡潔，我們只在 `libero_spatial` 子集上訓練，並以 `lerobot/smolvla_base` 作為
要進行參數高效微調（fine-tune）的模型：

```
lerobot-train \
 --policy.path=lerobot/smolvla_base \
 --policy.repo_id=your_hub_name/my_libero_smolvla \
 --dataset.repo_id=HuggingFaceVLA/libero \
 --policy.output_features=null \
 --policy.input_features=null \
 --policy.optimizer_lr=1e-3 \
 --policy.scheduler_decay_lr=1e-4 \
 --env.type=libero \
 --env.task=libero_spatial \
 --steps=100000 \
 --batch_size=32 \
 --peft.method_type=LORA \
 --peft.r=64 \
 --peft.lora_alpha=64
```

請注意 `--peft.method_type` 參數，它讓你選擇要使用哪一種 PEFT 方法。這裡我們使用
[LoRA](https://huggingface.co/docs/peft/main/en/package_reference/lora)（Low-Rank Adapter），這大概是目前
最流行的微調方法。低秩適應（low-rank adaptation）指的是只微調一個秩相對較低的矩陣，
而不是完整的權重矩陣。這個秩可以用 `--peft.r` 參數指定，LoRA 的縮放係數則以
`--peft.lora_alpha` 指定（其中 `scaling = lora_alpha / r`）。秩越高，
就越接近完整微調。

還有一些參數更多、也更複雜的方法，目前尚未支援。如果你希望支援特定的 PEFT 方法，
歡迎提出 issue。

預設情況下，PEFT 會以 SmolVLA 中 LM expert 的 `q_proj` 與 `v_proj` 層為目標，同時也會以
狀態與動作的投影矩陣為目標，因為它們最可能與任務相關。如果你需要以其他層為目標，
可以使用 `--peft.target_modules` 指定。至於支援哪些輸入，請參閱對應 PEFT 方法的
文件（例如 [LoRA 的 target_modules 說明](https://huggingface.co/docs/peft/main/en/package_reference/lora#peft.LoraConfig.target_modules)）。
通常支援後綴清單或正規表示式。例如，若要改以 `lm_expert` 的 MLP 為目標，而不是
`q` 與 `v` 投影，請使用：

```
--peft.target_modules='(model\.vlm_with_expert\.lm_expert\..*\.(down|gate|up)_proj|.*\.(state_proj|action_in_proj|action_out_proj|action_time_mlp_in|action_time_mlp_out))'
```

如果你需要完整微調某一層，而不只是對它做適應，可以將層的後綴清單
傳給 `--peft.full_training_modules` 參數：

```
--peft.full_training_modules=["state_proj"]
```

與完整微調相比，學習率與排程的目標學習率通常可以放大 10 倍
（例如一般為 1e-4，使用 LoRA 時則為 1e-3）。
