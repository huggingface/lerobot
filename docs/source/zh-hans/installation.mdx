# 安装

本指南使用 `conda`（通过 miniforge）来管理环境（推荐）。如果你偏好其他环境管理器（例如 `uv`、`venv`），请确保你有 Python >=3.12 并支持 PyTorch >= 2.10，然后跳到 [环境设置](#step-2-environment-setup)。

## 步骤 1（仅限 `conda`）：安装 [`miniforge`](https://conda-forge.org/download/)

```bash
wget "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-$(uname)-$(uname -m).sh"
bash Miniforge3-$(uname)-$(uname -m).sh
```

### 安装 `ffmpeg`（用于视频解码）

LeRobot 默认使用 [TorchCodec](https://github.com/meta-pytorch/torchcodec) 进行视频解码，这需要 `ffmpeg`。

> [!NOTE]
> **平台支持：** TorchCodec **不可用于** macOS Intel (x86_64)、Linux ARM (aarch64, arm64, armv7l) 或 PyTorch < 2.8 的 Windows。在这些平台上，LeRobot 会自动回退到 `pyav`——因此你无需安装 `ffmpeg`，可以跳到步骤 3。

如果你的平台支持 TorchCodec，请使用以下方法之一安装 `ffmpeg`：

<!-- prettier-ignore-start -->

<hfoptions id="install_ffmpeg">
<hfoption id="conda (任何 PyTorch 版本)">

在你的 conda 环境中安装 `ffmpeg`。这适用于 **所有 PyTorch 版本**，并且是 **PyTorch < 2.10 所必需的**：

```bash
conda install ffmpeg -c conda-forge
```

> [!TIP]
> 这通常会安装 `ffmpeg 8.X` 并带有 `libsvtav1` 编码器。如果遇到问题（例如 `libsvtav1` 缺失——使用 `ffmpeg -encoders` 检查——或与 `torchcodec` 版本不匹配），你可以使用以下命令显式安装 `ffmpeg 7.1.1`：
>
> ```bash
> conda install ffmpeg=7.1.1 -c conda-forge
> ```

</hfoption>
<hfoption id="uv (仅限 PyTorch >= 2.10)">

从 **PyTorch >= 2.10**（TorchCodec ≥ 0.10）开始，TorchCodec 可以动态链接到系统范围的 `ffmpeg` 安装。这在使用 `uv` 或其他非 `conda` 环境管理器时很有用：

```bash
# Ubuntu/Debian
sudo apt install ffmpeg

# macOS (Apple Silicon)
brew install ffmpeg
```

> [!IMPORTANT]
> 系统范围的 `ffmpeg` **仅在 PyTorch >= 2.10**（TorchCodec ≥ 0.10）时受支持。对于较旧的 PyTorch 版本，你**必须**改用 `conda install ffmpeg -c conda-forge`。

</hfoption>
</hfoptions>
<!-- prettier-ignore-end -->

## 步骤 3：安装 LeRobot 🤗

基础 `lerobot` 安装故意保持**轻量级**——它只包含核心 ML 依赖项（PyTorch、torchvision、numpy、opencv、einops、draccus、huggingface-hub、gymnasium、safetensors）。较重的依赖项通过可选 extras 进行控制，因此你只需安装所需的内容。

### 从源码安装

首先，克隆仓库并进入目录：

```bash
git clone https://github.com/huggingface/lerobot.git
cd lerobot
```

然后，以可编辑模式安装库。如果你计划为代码做贡献，这很有用。

<!-- prettier-ignore-start -->
<hfoptions id="install_lerobot_src">
<hfoption id="conda">
```bash
pip install -e ".[core_scripts]"  # 用于机器人工作流（录制、回放、校准）
pip install -e ".[training]"      # 用于训练策略
pip install -e ".[all]"           # 所有内容（所有策略、环境、硬件、开发工具）
```
</hfoption>
<hfoption id="uv">
```bash
uv pip install -e ".[core_scripts]"  # 用于机器人工作流（录制、回放、校准）
uv pip install -e ".[training]"      # 用于训练策略
uv pip install -e ".[all]"           # 所有内容（所有策略、环境、硬件、开发工具）
```
</hfoption>

_这仅安装核心 ML 依赖项。对于大多数工作流，你需要添加 extras。_

**功能 Extras：**
LeRobot 提供**面向功能的 extras**，映射到常见的工作流。如果你使用 `uv`，请将以下命令中的 `pip install` 替换为 `uv pip install`。

| Extra      | 添加的内容                                | 典型用例                    |
| ---------- | ------------------------------------------- | ----------------------------------- |
| `dataset`  | `datasets`, `av`, `torchcodec`, `jsonlines` | 加载和创建数据集         |
| `training` | `dataset` + `accelerate`, `wandb`           | 训练策略                   |
| `hardware` | `pynput`, `pyserial`, `deepdiff`            | 连接到真实机器人           |
| `viz`      | `rerun-sdk`                                 | 录制/评估期间的可视化 |

**组合 Extras** 为常见的 CLI 脚本组合功能 extras：

| Extra          | 包括                       | 典型用例                                        |
| -------------- | ------------------------------ | ------------------------------------------------------- |
| `core_scripts` | `dataset` + `hardware` + `viz` | `lerobot-record`、`lerobot-replay`、`lerobot-calibrate` |
| `evaluation`   | `av`                           | `lerobot-eval`（根据需要添加策略和环境 extras）      |
| `dataset_viz`  | `dataset` + `viz`              | `lerobot-dataset-viz`、`lerobot-imgtransform-viz`       |

```bash
pip install 'lerobot[core_scripts]'          # 录制、回放、校准
pip install 'lerobot[training]'              # 训练策略
pip install 'lerobot[core_scripts,training]' # 录制 + 训练
pip install 'lerobot[all]'                   # 所有内容
```

**策略、环境和硬件 extras** 仍然可用于特定依赖项：

```bash
pip install 'lerobot[pi]'             # Pi0/Pi0.5/Pi0-FAST 策略依赖
pip install 'lerobot[smolvla]'        # SmolVLA 策略依赖
pip install 'lerobot[diffusion]'      # Diffusion 策略依赖（diffusers）
pip install 'lerobot[aloha,pusht]'    # 模拟环境
pip install 'lerobot[feetech]'        # Feetech 电机支持
```

_多个 extras 可以组合（例如 `.[core_scripts,pi,pusht]`）。有关可用 extras 的完整列表，请参阅 `pyproject.toml`。_

### PyTorch CUDA 变体（仅限 Linux）

在 Linux 上，安装路径决定你获得哪个 CUDA wheel。macOS 和 Windows 安装使用 PyPI 默认值（分别为 MPS / CPU / CUDA-Windows wheel），可以跳过本节。

<!-- prettier-ignore-start -->

<hfoptions id="cuda_variant">
<hfoption id="uv-source">

**通过 `uv` 安装源码（`uv sync` 或 `uv pip install -e .`）**

`torch` 和 `torchvision` 被项目固定到 **CUDA 12.8** PyTorch 索引（`https://download.pytorch.org/whl/cu128`，驱动最低要求 **570.86**）——涵盖 Ampere/Ada/Hopper/Blackwell GPU。对于典型的 NVIDIA 设置，无需操作。

要为不同的 CUDA 变体覆盖：

```bash
uv pip install --force-reinstall torch torchvision \
    --index-url https://download.pytorch.org/whl/cu126   # 较旧的驱动；或 cu130 用于 Blackwell 驱动 ≥ 580
```

</hfoption>
<hfoption id="pip-conda">

**通过 `pip`/`conda` 安装源码，或从 PyPI `pip install lerobot`**

PyPI 默认 torch wheel 目前是 cu130 绑定的 Linux wheel，驱动最低要求 **580.65**。

要选择特定的 CUDA 变体：

**使用 `pip` 或 `conda`**——首先使用显式索引安装 torch，然后安装 lerobot：

```bash
pip install --index-url https://download.pytorch.org/whl/cu128 torch torchvision
pip install -e ".[all]"          # 源码
# — 或 —
pip install lerobot              # 来自 PyPI
```

**使用 `uv` 从 PyPI 安装**——通过 `--torch-backend` 一键安装（uv ≥ 0.6）：

```bash
uv pip install --torch-backend cu128 lerobot
```

支持的值包括 `auto`、`cpu`、`cu126`、`cu128`、`cu129`、`cu130`，以及各种 `rocm*` 和 `xpu`。根据你的驱动进行交换。

</hfoption>
</hfoptions>

### 故障排除

如果遇到构建错误，你可能需要安装额外的系统依赖项：`cmake`、`build-essential` 和 `ffmpeg libs`。
要为 Linux 安装这些，运行：

```bash
sudo apt-get install cmake build-essential python3-dev pkg-config libavformat-dev libavcodec-dev libavdevice-dev libavutil-dev libswscale-dev libswresample-dev libavfilter-dev
```

对于其他系统，请参阅：[编译 PyAV](https://pyav.org/docs/develop/overview/installation.html#bring-your-own-ffmpeg)

## 可选依赖项

LeRobot 为特定功能提供可选 extras。多个 extras 可以组合（例如 `.[aloha,feetech]`）。有关所有可用 extras，请参阅 `pyproject.toml`。如果你使用 `uv`，请将以下命令中的 `pip install` 替换为 `uv pip install`。

### 模拟

安装环境包：`aloha`（[gym-aloha](https://github.com/huggingface/gym-aloha)），或 `pusht`（[gym-pusht](https://github.com/huggingface/gym-pusht)）。
这些会自动包含 `dataset` extra。

```bash
pip install -e ".[aloha]" # 或例如 "[pusht]"
```

### 电机控制

对于 Koch v1.1 安装 Dynamixel SDK，对于 SO100/SO101/Moss 安装 Feetech SDK。

```bash
pip install -e ".[feetech]" # 或例如 "[dynamixel]"
```

### 实验跟踪

Weights and Biases 包含在 `training` extra 中。要使用 [Weights and Biases](https://docs.wandb.ai/quickstart) 进行实验跟踪，请使用以下命令登录：

```bash
wandb login
```
