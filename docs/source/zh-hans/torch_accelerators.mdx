# PyTorch 加速器

LeRobot 支持多种硬件加速选项，适用于训练和推理。

这些选项包括：

- **CPU**：CPU 执行所有计算，不使用专用加速器
- **CUDA**：使用 NVIDIA 和 AMD GPU 加速
- **MPS**：使用 Apple Silicon GPU 加速
- **XPU**：使用 Intel 集成和独立 GPU 加速

## 快速开始

要使用特定的加速器，需要安装合适版本的 PyTorch。

对于 CPU、CUDA 和 MPS 后端，请按照 [PyTorch 安装页面](https://pytorch.org/get-started/locally)上的说明进行操作。
对于 XPU 后端，请按照 [PyTorch 文档](https://docs.pytorch.org/docs/stable/notes/get_start_xpu.html)中的说明进行操作。

### 验证安装

安装完成后，可以通过以下命令验证加速器的可用性：

```python
import torch
print(torch.<后端名称>.is_available())  # <后端名称> 为 cuda、mps 或 xpu
```

## 如何运行训练或评估

要选择所需的加速器，在运行 `lerobot-train` 或 `lerobot-eval` 时使用 `--policy.device` 标志。例如，要在 Apple Silicon 上使用 MPS，运行：

```bash
lerobot-train
    --policy.device=mps ...
```

```bash
lerobot-eval \
    --policy.device=mps ...
```

不过，在大多数情况下，系统会自动检测到加速器的存在，因此可以从 CLI 命令中省略 `policy.device` 参数。
