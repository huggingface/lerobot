# SmolVLA

SmolVLA 是 Hugging Face 面向机器人领域推出的轻量级基础模型（foundation model）。它专为在 LeRobot 数据集上轻松进行微调（fine-tuning）而设计，帮助你加快开发进程！

## 配置环境

1. 按照我们的[安装指南](./installation)安装 LeRobot。
2. 运行以下命令安装 SmolVLA 依赖项：

   ```bash
   pip install -e ".[smolvla]"
   ```

## 收集数据集

SmolVLA 是一个基础模型，因此，如果要在你的使用环境中获得最佳性能，就需要使用你自己的数据对其进行微调。
我们建议首先录制约 50 个任务回合（episode）。请按照我们的指南开始操作：[录制数据集](./il_robots)

<Tip>

请确保数据集中针对你引入的每种变化都有足够多的示范样本（例如，在方块取放任务中，方块在桌面上的不同位置）。

建议参考下面这个用于 [SmolVLA 论文](https://huggingface.co/papers/2506.01844)的数据集：

🔗 [SVLA SO100 PickPlace](https://huggingface.co/spaces/lerobot/visualize_dataset?path=%2Flerobot%2Fsvla_so100_pickplace%2Fepisode_0)

在这个数据集中，我们针对 5 个不同的方块位置录制了 50 个回合。对于每个位置，我们都收集了 10 个取放交互回合。通过多次重复每种变化，这种数据结构帮助模型获得了更好的泛化能力。我们还尝试过一个类似的、但仅包含 25 个回合的数据集，但数据量不足，导致性能不佳。因此，数据的质量和数量无疑是关键因素。
将数据集发布到 Hub 后，你就可以使用我们的微调脚本，让 SmolVLA 适应你的应用场景。

</Tip>

## 使用你的数据微调 SmolVLA

使用我们的 450M 预训练模型 [`smolvla_base`](https://hf.co/lerobot/smolvla_base)，并在你的数据上对其进行微调。
在单张 A100 GPU 上训练 20k 步大约需要 4 小时。你应根据模型性能和具体使用场景调整训练步数。

没有 GPU 设备时，可以使用我们的 [![Google Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/huggingface/notebooks/blob/main/lerobot/training-smolvla.ipynb) 笔记本进行训练。

通过 `--dataset.repo_id` 将你的数据集传递给训练脚本。如果想要测试安装是否成功，请运行以下命令。这里使用的是我们为 [SmolVLA 论文](https://huggingface.co/papers/2506.01844)收集的一个数据集。

```bash
cd lerobot && lerobot-train \
  --policy.path=lerobot/smolvla_base \
  --dataset.repo_id=${HF_USER}/mydataset \
  --batch_size=64 \
  --steps=20000 \
  --output_dir=outputs/train/my_smolvla \
  --job_name=my_smolvla_training \
  --policy.device=cuda \
  --wandb.enable=true
```

<Tip>
  你可以先使用较小的批次大小，并在 GPU 允许且数据加载时间仍然较短的情况下，
  逐步增大批次大小。
</Tip>

微调是一门艺术。要全面了解可用的微调选项，请运行：

```bash
lerobot-train --help
```

## 评估微调后的模型并实时运行

与录制回合时一样，建议你先登录 HuggingFace Hub。可以按照相应步骤操作：[录制数据集](./il_robots)。
登录后，可以运行以下命令，在你的使用环境中执行推理：

```bash
lerobot-rollout \
  --strategy.type=base \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyACM0 \ # <- 使用你的端口
  --robot.id=my_blue_follower_arm \ # <- 使用你的机器人 ID
  --robot.cameras="{ front: {type: opencv, index_or_path: 8, width: 640, height: 480, fps: 30}}" \ # <- 使用你的摄像头配置
  --task="Grasp a lego block and put it in the bin." \ # <- 使用录制数据集时所用的相同任务描述
  # <- RTC 可选；在低算力硬件上运行时使用 \
  # --inference.type=rtc \
  # --inference.rtc.execution_horizon=10 \
  # --inference.rtc.max_guidance_weight=10.0 \
  # <- Teleop 可选；如需在各回合之间进行遥操作，请使用 \
  # --teleop.type=so100_leader \
  # --teleop.port=/dev/ttyACM0 \
  # --teleop.id=my_red_leader_arm \
  # --display_data=true # 可选；如需查看摄像头画面，请使用 \
  --policy.path=HF_USER/FINETUNE_MODEL_NAME # <- 使用你的微调模型
```

你可以根据你的评估设置，配置录制时长以及要为评估套件录制的回合数。
