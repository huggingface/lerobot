# 摄像头[[cameras]]

摄像头（Cameras）提供策略（policy）所看到的图像观测（observation）。每个后端（backend）——OpenCV、Intel RealSense、Reachy 2——都实现 [`Camera`] 接口，因此更换硬件（hardware）不会改变读取帧（frame）的代码。

有关选择和配置摄像头的说明，请参阅[摄像头指南](../cameras)；有关核心设备之外的设备，请参阅[第三方摄像头与传感器](../third_party_sensors)。
