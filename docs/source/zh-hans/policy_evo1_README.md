# EVO1

EVO1 是一个用于机器人控制的视觉-语言-动作（VLA）策略。LeRobot 集成使用 InternVL3 视觉-语言骨干网络配合流匹配动作头，并通过标准 LeRobot 策略 API 支持分阶段训练。

上游 EVO1 项目可在 [MINT-SJTU/Evo-1](https://github.com/MINT-SJTU/Evo-1) 获取。
