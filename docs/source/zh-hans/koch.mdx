在以下步骤中，我们将说明如何组装 Koch v1.1 机器人。

## 订购并组装部件[[order-and-assemble-the-parts]]

请遵循此 [README](https://github.com/jess-moss/koch-v1-1) 中提供的采购和组装说明。它将指导你设置从臂（follower arm）和主臂（leader arm），如下图所示。

如需通过视频了解组装过程，可以参考[此视频教程](https://youtu.be/8nQIg9BwwTk)。

> [!WARNING]
> 自该视频制作以来，我们简化了配置阶段。因此，有两点与该视频中的说明不同：
>
> - 不要立即插上所有电机线缆，请等待在[配置电机](#configure-the-motors)中的指示后再操作。
> - 不要立即将控制器板（PCB）拧到底座上，请等待在[配置电机](#configure-the-motors)中的指示后再操作。

## 安装 LeRobot 🤗[[install-lerobot]]

要安装 LeRobot，请遵循我们的[安装指南](./installation)。

除这些说明外，你还需要安装 Dynamixel 电机支持：

```bash
pip install -e ".[dynamixel]"
```

## 配置电机[[configure-the-motors]]

### 1. 查找与每个机械臂关联的 USB 端口[[1-find-the-usb-ports-associated-with-each-arm]]

要查找每个总线舵机适配器（bus servo adapter）的端口，请运行以下脚本：

```bash
lerobot-find-port
```

<hfoptions id="example">
<hfoption id="Mac">

示例输出：

```
Finding all available ports for the MotorBus.
['/dev/tty.usbmodem575E0032081', '/dev/tty.usbmodem575E0031751']
Remove the USB cable from your MotorsBus and press Enter when done.

[...Disconnect corresponding leader or follower arm and press Enter...]

The port of this MotorsBus is /dev/tty.usbmodem575E0032081
Reconnect the USB cable.
```

找到的端口是：`/dev/tty.usbmodem575E0032081`，它对应你的主臂（leader arm）或从臂（follower arm）。

</hfoption>
<hfoption id="Linux">

在 Linux 上，你可能需要通过运行以下命令来授予 USB 端口访问权限：

```bash
sudo chmod 666 /dev/ttyACM0
sudo chmod 666 /dev/ttyACM1
```

示例输出：

```
Finding all available ports for the MotorBus.
['/dev/ttyACM0', '/dev/ttyACM1']
Remove the usb cable from your MotorsBus and press Enter when done.

[...Disconnect corresponding leader or follower arm and press Enter...]

The port of this MotorsBus is /dev/ttyACM1
Reconnect the USB cable.
```

找到的端口是：`/dev/ttyACM1`，它对应你的主臂（leader arm）或从臂（follower arm）。

</hfoption>
</hfoptions>

### 2. 设置电机 ID 和波特率[[2-set-the-motors-ids-and-baudrates]]

每个电机（motor）通过总线上的唯一 ID 进行标识。全新电机通常带有默认 ID `1`。为了让电机与控制器（controller）之间的通信正常工作，我们首先需要为每个电机设置一个唯一的、不同的 ID。此外，总线上数据传输的速度由波特率（baudrate）决定。为了彼此通信，控制器和所有电机都需要配置为相同的波特率。

为此，我们首先需要将控制器（controller）与每个电机单独连接，以便进行设置。由于我们会将这些参数写入电机内部存储器（EEPROM）的非易失性区域，因此只需执行一次。

如果你要重新利用来自另一台机器人的电机，可能也需要执行此步骤，因为 ID 和波特率很可能不匹配。

#### 从臂[[follower]]

将来自计算机的 USB 线缆和 5V 电源连接到从臂（follower arm）的控制器板（controller board）。然后，使用上一步中获取的端口运行以下命令，或运行 API 示例。你还需要使用 `id` 参数为主臂（leader arm）指定一个名称。

有关如何设置电机 ID 的可视化参考，请参阅[此视频](https://huggingface.co/docs/lerobot/zh-hans/so101#setup-motors-video)，其中我们按照 SO101 机械臂的流程进行操作。

<hfoptions id="setup_motors">
<hfoption id="Command">

```bash
lerobot-setup-motors \
    --robot.type=koch_follower \
    --robot.port=/dev/tty.usbmodem575E0031751 # <- 在此粘贴上一步找到的端口
```

</hfoption>
<hfoption id="API example">

<!-- prettier-ignore-start -->
```python
from lerobot.robots.koch_follower import KochFollower, KochFollowerConfig

config = KochFollowerConfig(
    port="/dev/tty.usbmodem575E0031751",
    id="my_awesome_follower_arm",
)
follower = KochFollower(config)
follower.setup_motors()
```
<!-- prettier-ignore-end -->

</hfoption>
</hfoptions>

你应该会看到以下指令。

```
Connect the controller board to the 'gripper' motor only and press enter.
```

按照指示，连接夹爪电机。确保它是唯一连接到控制器板的电机，并且该电机本身尚未以菊花链方式连接到任何其他电机。当你按下 `[Enter]` 时，脚本会自动为该电机设置 ID 和波特率。

<details>
<summary>故障排除</summary>

如果此时出现错误，请检查线缆并确保它们已正确插好：

<ul>
  <li>电源</li>
  <li>计算机与控制器板之间的 USB 线缆</li>
  <li>从控制器板到电机的 3 针线缆</li>
</ul>

如果你使用的是 Waveshare 控制器板，请确保两个跳线帽设置在 `B` 通道（USB）上。

</details>

然后你应该会看到以下消息：

```
'gripper' motor id set to 6
```

接着是下一条指令：

```
Connect the controller board to the 'wrist_roll' motor only and press enter.
```

你可以从控制器板断开 3 针线缆，但另一端可以保持与夹爪电机连接，因为它已经处在正确位置。现在，将另一根 3 针线缆插入腕部旋转电机，并将其连接到控制器板。与前一个电机一样，请确保它是唯一连接到控制器板的电机，并且该电机本身没有连接到任何其他电机。

按照指示对每个电机重复此操作。

> [!TIP]
> 在按下 Enter 前，请检查每一步的接线。例如，在操作控制器板时，电源线可能会断开。

完成后，脚本会直接结束，此时电机即可使用。现在，你可以将每个电机的 3 针线缆插到下一个电机，并将第一个电机（id=1 的 'shoulder pan'）的线缆连接到控制器板，后者现在可以安装到机械臂的底座上。

#### 主臂[[leader]]

对主臂（leader arm）执行相同步骤，但请相应地修改命令或脚本。

<hfoptions id="setup_motors">
<hfoption id="Command">

```bash

    --teleop.type=koch_leader \
    --teleop.port=/dev/tty.usbmodem575E0031751 \  # <- 在此粘贴上一步找到的端口
```

</hfoption>
<hfoption id="API example">

<!-- prettier-ignore-start -->
```python
from lerobot.teleoperators.koch_leader import KochLeader, KochLeaderConfig

config = KochLeaderConfig(
    port="/dev/tty.usbmodem575E0031751",
    id="my_awesome_leader_arm",

```

</hfoption>
</hfoptions>

## 校准[[calibrate]]

接下来，你需要校准机器人，以确保主臂（leader arm）和从臂（follower arm）处于相同物理位置时具有相同的位置值。
校准（calibration）过程非常重要，因为它可以让在一台机器人上训练的神经网络在另一台机器人上工作。

#### 从臂[[follower-1]]

运行以下命令或 API 示例来校准从臂（follower arm）：

<hfoptions id="calibrate_follower">
<hfoption id="Command">

```bash
lerobot-calibrate \
    --robot.type=koch_follower \
    --robot.port=/dev/tty.usbmodem58760431551 \ # <- 你的机器人端口
    --robot.id=my_awesome_follower_arm  # <- 为机器人指定一个唯一名称
```

</hfoption>
<hfoption id="API example">

<!-- prettier-ignore-start -->
```python
from lerobot.robots.koch_follower import KochFollowerConfig, KochFollower

config = KochFollowerConfig(
    port="/dev/tty.usbmodem585A0076891",
    id="my_awesome_follower_arm",
)

follower = KochFollower(config)
follower.connect(calibrate=False)
follower.calibrate()
follower.disconnect()
```
<!-- prettier-ignore-end -->

</hfoption>
</hfoptions>

我们统一了大多数机器人的校准方法。因此，此 Koch 机械臂的校准步骤与 SO100 和 SO101 的步骤相同。首先，我们必须将机器人移动到每个关节都处于其活动范围中间的位置，然后按下 `Enter`。其次，我们让所有关节完成其完整活动范围的运动。可以[在此处](https://huggingface.co/docs/lerobot/zh-hans/so101#calibration-video)找到将 SO101 的相同过程作为参考的视频。

#### 主臂[[leader-1]]

对主臂（leader arm）执行相同步骤进行校准，运行以下命令或 API 示例：

<hfoptions id="calibrate_leader">
<hfoption id="Command">

```bash
lerobot-calibrate \
    --teleop.type=koch_leader \
    --teleop.port=/dev/tty.usbmodem58760431551 \ # <- 你的机器人端口
    --teleop.id=my_awesome_leader_arm  # <- 为机器人指定一个唯一名称
```

</hfoption>
<hfoption id="API example">

<!-- prettier-ignore-start -->
```python
from lerobot.teleoperators.koch_leader import KochLeaderConfig, KochLeader

config = KochLeaderConfig(
    port="/dev/tty.usbmodem575E0031751",
    id="my_awesome_leader_arm",
)

leader = KochLeader(config)
leader.connect(calibrate=False)
leader.calibrate()
leader.disconnect()
```
<!-- prettier-ignore-end -->

</hfoption>
</hfoptions>
