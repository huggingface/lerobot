# reBot B601[[rebot-b601]]

reBot B601 是 Seeed Studio 推出的开源机械臂（robot arm），面向模仿学习（imitation learning）和具身智能（embodied AI）。一套设置会将一个 6 自由度（6-DOF）从臂（follower arm）与夹爪（gripper）以及一个 reBot Arm 102 主臂（leader arm）配对，用于遥操作（teleoperation）。

从臂可配备 Damiao（DM）或 RobStride（RS）电机。两种版本使用相同的 LeRobot 机器人类型和关节名称；通过 `--robot.motor_family` 选择硬件。

| 版本                                                               | `motor_family` | 电机                                    | 默认连接          |
| ------------------------------------------------------------------ | -------------- | --------------------------------------- | ----------------- |
| [B601-DM](https://wiki.seeedstudio.com/rebot_arm_b601_dm_lerobot/) | `dm`           | Damiao（`4340P` 底座，`4310` 腕部）     | Damiao 串行桥接器 |
| [B601-RS](https://wiki.seeedstudio.com/rebot_arm_b601_rs_lerobot/) | `rs`           | RobStride（`rs-06` 底座，`rs-00` 腕部） | 原生 CAN          |

本指南涵盖单臂和双臂设置的硬件设置、校准、遥操作和录制。

## 硬件与安全[[hardware-and-safety]]

请使用适用于你的从臂的 Seeed Studio 指南来组装、接线和配置电机：[B601-DM](https://wiki.seeedstudio.com/rebot_arm_b601_dm_lerobot/) 或 [B601-RS](https://wiki.seeedstudio.com/rebot_arm_b601_rs_lerobot/)。

<Tip warning={true}>
  将从臂固定在稳定表面上，并保持其工作空间清空。当扭矩被禁用或程序断开连接时，
  要支撑住机械臂，因为它可能会在重力作用下移动。如果在操作过程中电源或数据线断开，
  请停止程序，将主臂和从臂返回到零位，然后重新连接并重启。
</Tip>

## 安装 LeRobot 🤗[[install-lerobot]]

请遵循[安装指南](./installation)，然后安装 reBot 支持：

```bash
pip install -e ".[rebot]"
```

这会为从臂安装 `motorbridge`，并为 reBot Arm 102 主臂安装 `motorbridge-smart-servo`。

## 连接硬件[[connect-the-hardware]]

DM 默认使用其串行桥接器，也可选择使用原生 CAN。RS 需要使用原生 CAN。

| `can_adapter` | 用途                           | 示例端口       |
| ------------- | ------------------------------ | -------------- |
| `damiao`      | Damiao 串行桥接器；仅适用于 DM | `/dev/ttyACM0` |
| `socketcan`   | MotorBridge 原生 CAN；RS 必需  | `can0`         |

电机系列（motor family）会选择默认适配器。若要改为通过原生 CAN 运行 DM，请添加 `--robot.can_adapter=socketcan`，并将其 CAN 通道用作 `--robot.port`。

### 串行桥接器[[serial-bridge]]

使用 `lerobot-find-port` 识别 DM 串行桥接器和主臂端口。如果设备名称难以区分，请一次连接一个串行设备。

```bash
lerobot-find-port
```

<Tip warning={true}>
  在 Linux 上，如果 `brltty` 占用了串行设备，请将其移除（`sudo apt remove
  brltty`）。 你可能还需要使用 `sudo chmod 666 /dev/ttyACM* /dev/ttyUSB*`
  获取临时访问权限。
</Tip>

### 原生 CAN[[native-can]]

`socketcan` 配置名称在各平台上保持不变。Linux 使用 SocketCAN。macOS 需要兼容的 PCAN 适配器和 MacCAN PCBUSB 运行时。Windows 的原生 CAN 支持是实验性的，并且需要 PEAK PCAN 适配器和 PCAN-Basic。有关安装详细信息，请参阅 [MotorBridge 平台设置](https://github.com/motorbridge/motorbridge/tree/v0.5.1)。

在 Linux 上，连接 RS 从臂之前，请将每个原生 CAN 接口配置为 1 Mbps：

```bash
sudo ip link set can0 down
sudo ip link set can0 type can bitrate 1000000
sudo ip link set can0 up
ip -details link show can0
```

将 `can0` 替换为你的 CAN 后端提供的通道。双臂原生 CAN 设置需要单独的通道，例如 `can0` 和 `can1`，因为两个机械臂使用相同的电机 ID。

## 设备类型[[device-types]]

| 类型                     | 设备                    |
| ------------------------ | ----------------------- |
| `rebot_b601_follower`    | 单从臂                  |
| `bi_rebot_b601_follower` | 双臂从臂                |
| `rebot_102_leader`       | 单 reBot Arm 102 主臂   |
| `bi_rebot_102_leader`    | 双臂 reBot Arm 102 主臂 |

`motor_family` 默认为 `dm`。在双臂配置中，每个机械臂都有各自的 `left_arm_config.*` 或 `right_arm_config.*` 设置，并且可以独立选择其电机系列。

## 校准[[calibration]]

校准会将当前物理姿态设置为电机零位，并保存 LeRobot 校准文件。将每个机械臂置于下图所示的零位，并让夹爪完全闭合，然后在出现提示时按 <kbd>ENTER</kbd>。

### 从臂[[follower]]

<hfoptions id="calibrate-follower">
<hfoption id="Single arm (DM)">

```bash
lerobot-calibrate \
    --robot.type=rebot_b601_follower \
    --robot.motor_family=dm \
    --robot.port=/dev/ttyACM0 \
    --robot.id=follower
```

</hfoption>
<hfoption id="Single arm (RS)">

```bash
lerobot-calibrate \
    --robot.type=rebot_b601_follower \
    --robot.motor_family=rs \
    --robot.port=can0 \
    --robot.id=follower
```

</hfoption>
<hfoption id="Dual arm (DM)">

校准会先针对左从臂运行，然后针对右从臂运行。

```bash
lerobot-calibrate \
    --robot.type=bi_rebot_b601_follower \
    --robot.id=bi_follower \
    --robot.left_arm_config.motor_family=dm \
    --robot.left_arm_config.port=/dev/ttyACM0 \
    --robot.right_arm_config.motor_family=dm \
    --robot.right_arm_config.port=/dev/ttyACM1
```

对于两个 RS 从臂，请将两个系列都设置为 `rs`，并为两个端口使用各自的原生 CAN 通道。每个机械臂的校准文件使用 `_left` 和 `_right` 后缀。

</hfoption>
</hfoptions>

## 录制数据集[[record-a-dataset]]

在录制之前测试遥操作。要添加摄像头，请先使用以下命令识别它：

```bash
lerobot-find-cameras opencv
```

### 单臂[[single-arm]]

以下示例使用一个 OpenCV 摄像头在本地录制五个 DM 片段（episode）：

```bash
lerobot-record \
    --robot.type=rebot_b601_follower \
    --robot.motor_family=dm \
    --robot.port=/dev/ttyACM0 \
    --robot.id=follower \
    --robot.cameras='{"front": {"type": "opencv", "index_or_path": 0, "width": 640, "height": 480, "fps": 30}}' \
    --teleop.type=rebot_102_leader \
    --teleop.port=/dev/ttyUSB0 \
    --teleop.id=leader \
    --dataset.repo_id=your_username/rebot-dm-test \
    --dataset.single_task="Pick up the object" \
    --dataset.num_episodes=5 \
    --dataset.episode_time_s=30 \
    --dataset.reset_time_s=10 \
    --dataset.push_to_hub=false \
    --display_data=true
```

对于 RS，将 `motor_family` 改为 `rs`，并将机器人端口改为原生 CAN 通道。对于仅测试电机的场景，请移除摄像头参数。

### 双臂[[bimanual]]

这个 DM 示例录制一个共享的顶部摄像头以及每个机械臂一个腕部摄像头。数据集摄像头键为 `top`、`left_wrist` 和 `right_wrist`。

```bash
lerobot-record \
    --robot.type=bi_rebot_b601_follower \
    --robot.id=bi_follower \
    --robot.left_arm_config.motor_family=dm \
    --robot.left_arm_config.port=/dev/ttyACM0 \
    --robot.right_arm_config.motor_family=dm \
    --robot.right_arm_config.port=/dev/ttyACM1 \
    --robot.cameras='{
      top: {
        type: opencv,
        index_or_path: "/dev/video2",
        width: 640,
        height: 480,
        fps: 30,
        fourcc: "MJPG"
      }
    }' \
    --robot.left_arm_config.cameras='{
      wrist: {
        type: opencv,
        index_or_path: "/dev/video0",
        width: 640,
        height: 480,
        fps: 30,
        fourcc: "MJPG"
      }
    }' \
    --robot.right_arm_config.cameras='{
      wrist: {
        type: opencv,
        index_or_path: "/dev/video4",
        width: 640,
        height: 480,
        fps: 30,
        fourcc: "MJPG"
      }
    }' \
    --teleop.type=bi_rebot_102_leader \
    --teleop.id=bi_leader \
    --teleop.left_arm_config.port=/dev/ttyUSB0 \
    --teleop.right_arm_config.port=/dev/ttyUSB1 \
    --dataset.repo_id=local/rebot-bimanual-dm-camera-test \
    --dataset.root=/tmp/rebot-bimanual-dm-camera-test \
    --dataset.single_task="Test coordinated movement of both reBot DM arms" \
    --dataset.fps=30 \
    --dataset.num_episodes=2 \
    --dataset.episode_time_s=20 \
    --dataset.reset_time_s=10 \
    --dataset.push_to_hub=false \
    --display_data=false
```

> [!TIP]
> 对于双臂 RS 设置，请将两个电机系列都设置为 `rs`，并使用各自的原生 CAN 通道。混合设置可以为一只机械臂选择 `dm`，为另一只选择 `rs`。

请参阅[机器人模仿学习](./il_robots)，以上传、回放、训练和评估策略（policy）。

## 高级控制[[advanced-controls]]

两种版本都公开相同的关节名称以及以度表示的公共位置。LeRobot 会将每个系列的电机方向符号应用于动作和观测（observation），因此策略（policy）和遥操作器无需转换电机符号。

- DM 默认对机械臂使用 MIT 控制，对夹爪使用 `force_pos`。`gripper_torque_ratio` 默认为 `0.07`；DM 还支持 `--robot.control_mode=pos_vel`。
- RS 使用 MIT 控制和力受限的阻抗夹爪，因为 MotorBridge 不为 RobStride 提供 `force_pos`。根据测得的夹爪运动，指令扭矩在移动时上限为 `3.5` N·m，在保持时上限为 `1.0` N·m。如果反馈失败，LeRobot 会尝试命令夹爪扭矩为零，然后禁用机械臂。
- `mit_kp`、`mit_kd` 和 `pos_vel_velocity` 可以接受一个适用于所有关节的标量，或一个以关节为键的映射。
- `max_relative_target` 限制命令与最新测得位置之间的差值。例如，`--robot.max_relative_target=5.0` 会将每个被命令的关节限制为五度的变化。
- `joint_limits` 可以选择以公共关节度数覆盖系列默认值。

从臂电机方向会根据电机系列在内部选择。如果某个遥操作关节朝错误方向移动，主臂的 `joint_directions` 仍然可以配置。

<Tip warning={true}>
  DM 和 RS 使用相同的坐标约定，但它们的几何结构、增益和动力学不同。
  在不同版本之间迁移之前，请验证策略（policy）和数据集。
</Tip>

## 故障排除[[troubleshooting]]

| 问题                     | 检查                                                                                       |
| ------------------------ | ------------------------------------------------------------------------------------------ |
| 串行设备缺失或忙         | 一次重新连接一个设备，重新运行 `lerobot-find-port`，检查权限，并在 Linux 上移除 `brltty`。 |
| 原生 CAN 无法连接        | 检查适配器运行时、通道名称、1 Mbps 比特率、电机电源、CAN 接线和终端电阻。                  |
| 遥操作关节朝错误方向移动 | 停止程序，确认 `motor_family`，并检查主臂的 `joint_directions`。                           |
| 校准未被复用             | 使用与校准期间相同的机器人或遥操作器 `id`。                                                |

有关组装、接线和特定于硬件的诊断，请参阅 Seeed Studio 的 [B601-DM](https://wiki.seeedstudio.com/rebot_arm_b601_dm_lerobot/) 和 [B601-RS](https://wiki.seeedstudio.com/rebot_arm_b601_rs_lerobot/) 指南。
