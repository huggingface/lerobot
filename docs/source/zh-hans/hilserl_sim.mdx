# 在仿真中训练 RL

本指南介绍如何在 LeRobot 框架中进行 Human-In-the-Loop (HIL) 强化学习时，使用 `gym_hil` 仿真环境替代真实机器人。

`gym_hil` 是一个提供 Gymnasium 兼容仿真环境的包，专为 Human-In-the-Loop 强化学习设计。这些环境允许你：

- 在仿真中训练 policy，在真实机器人训练之前测试 RL 流程

- 在仿真中使用手柄或键盘等外部设备收集演示数据

- 在 policy 学习过程中进行人工干预

目前，主要环境是基于 MuJoCo 的 Franka Panda 机器人仿真，包含拾取方块等任务。

## 安装

首先，在 LeRobot 环境中安装 `gym_hil` 包：

```bash
pip install -e ".[hilserl]"
```

## 需要什么？

- 一个手柄或键盘来控制机器人
- 一块 Nvidia GPU

## 配置

要在 LeRobot 中使用 `gym_hil`，你需要创建一个配置文件。示例可在[此处](https://huggingface.co/datasets/lerobot/config_examples/resolve/main/rl/gym_hil/env_config.json)获取。主要配置部分包括：

### 环境类型和任务

```json
{
  "env": {
    "type": "gym_manipulator",
    "name": "gym_hil",
    "task": "PandaPickCubeGamepad-v0",
    "fps": 10
  },
  "device": "cuda"
}
```

可用任务：

- `PandaPickCubeBase-v0`：基础环境
- `PandaPickCubeGamepad-v0`：手柄控制
- `PandaPickCubeKeyboard-v0`：键盘控制

### Processor 配置

```json
{
  "env": {
    "processor": {
      "control_mode": "gamepad",
      "gripper": {
        "use_gripper": true,
        "gripper_penalty": -0.02
      },
      "reset": {
        "control_time_s": 15.0,
        "fixed_reset_joint_positions": [
          0.0, 0.195, 0.0, -2.43, 0.0, 2.62, 0.785
        ]
      },
      "inverse_kinematics": {
        "end_effector_step_sizes": {
          "x": 0.025,
          "y": 0.025,
          "z": 0.025
        }
      }
    }
  }
}
```

重要参数：

- `gripper.gripper_penalty`：夹爪过度移动的惩罚
- `gripper.use_gripper`：是否启用夹爪控制
- `inverse_kinematics.end_effector_step_sizes`：末端执行器在 x、y、z 轴上的步长
- `control_mode`：设为 `"gamepad"` 使用手柄控制器

## 使用 LeRobot 的 HIL RL 运行

### 基本用法

运行环境，将 mode 设为 null：

```bash
python -m lerobot.rl.gym_manipulator --config_path path/to/gym_hil_env.json
```

### 录制 Dataset

收集 dataset 时，将 mode 设为 `record`，同时定义 repo_id 和要录制的 episode 数量：

```json
{
  "env": {
    "type": "gym_manipulator",
    "name": "gym_hil",
    "task": "PandaPickCubeGamepad-v0"
  },
  "dataset": {
    "repo_id": "username/sim_dataset",
    "root": null,
    "task": "pick_cube",
    "num_episodes_to_record": 10,
    "replay_episode": null,
    "push_to_hub": true
  },
  "mode": "record"
}
```

```bash
python -m lerobot.rl.gym_manipulator --config_path path/to/gym_hil_env.json
```

### 训练 Policy

训练 policy 时，获取[此处](https://huggingface.co/datasets/lerobot/config_examples/resolve/main/rl/gym_hil/train_config.json)的配置示例，然后运行 actor 和 learner 服务：

```bash
python -m lerobot.rl.actor --config_path path/to/train_gym_hil_env.json
```

在另一个终端中，运行 learner 服务：

```bash
python -m lerobot.rl.learner --config_path path/to/train_gym_hil_env.json
```

仿真环境提供了一种安全且可重复的方式来开发和测试 Human-In-the-Loop 强化学习组件，然后再部署到真实机器人上。
