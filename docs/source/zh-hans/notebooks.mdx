# 🤗 LeRobot 笔记本

本仓库包含 LeRobot 的示例笔记本。这些笔记本展示了如何使用标准化策略在真实或模拟数据集上训练策略。

---

### 训练 ACT

[ACT](https://huggingface.co/papers/2304.13705)（Action Chunking Transformer，动作分块转换器）是一种基于 Transformer 的模仿学习策略架构，它处理机器人状态和摄像头输入，生成平滑的分块动作序列。

我们提供了一个可直接运行的 Google Colab 笔记本，帮助您使用 Hugging Face Hub 上的数据集训练 ACT 策略，并可选择将日志记录到 Weights & Biases。

| 笔记本                                                                                                  | Colab                                                                                                                                                                               |
| :------------------------------------------------------------------------------------------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [使用 LeRobot 训练 ACT](https://github.com/huggingface/notebooks/blob/main/lerobot/training-act.ipynb) | [![在 Colab 中打开](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/huggingface/notebooks/blob/main/lerobot/training-act.ipynb) |

100k 步的预期训练时间：使用 NVIDIA A100 GPU，批次大小为 `64` 时约 1.5 小时。

### 训练 SmolVLA

[SmolVLA](https://huggingface.co/papers/2506.01844) 是一个小型但高效的视觉-语言-动作（Vision-Language-Action）模型。它体积紧凑，参数量为 4.5 亿，由 Hugging Face 开发。

我们提供了一个可直接运行的 Google Colab 笔记本，帮助您使用 Hugging Face Hub 上的数据集训练 SmolVLA 策略，并可选择将日志记录到 Weights & Biases。

| :---------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [使用 LeRobot 训练 SmolVLA](https://github.com/huggingface/notebooks/blob/main/lerobot/training-smolvla.ipynb) | [![在 Colab 中打开](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/huggingface/notebooks/blob/main/lerobot/training-smolvla.ipynb) |
