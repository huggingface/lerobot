# OpenArm[[openarm]]

[OpenArm](https://openarm.dev) 是一款开源 7 自由度（7DOF）人形机械臂，专为物理 AI 研究与部署而设计。

如需获取预组装或 DIY 的 OpenArm，并加入全球社区，请访问 [openarm.dev](https://openarm.dev) 浏览全球经过验证和认证的制造商。

## 有何独特之处？[[whats-unique]]

- **人体尺度设计**：OpenArm 采用类人比例设计，按身高约 160-165cm 的人进行缩放。这在实用可达范围与可控惯性之间提供了最佳平衡，以实现安全、响应迅速的操作。

- **安全优先架构**：OpenArm 采用 QDD 可反驱电机和高柔顺性设计，优先保障安全的人机交互，同时为真实任务保持实用的有效载荷能力（峰值 6.0kg / 额定 4.1kg）。

- **为耐用性而打造**：关键结构部件采用铝和不锈钢结构，确保在重复数据采集和持续研究使用中保持稳健性能。

- **完全可获取且可构建**：从 CNC 零件、3D 打印外壳到电气布线的每个组件，都设计为可由个人研究人员和实验室购买并构建，并提供完整的制造数据。

- **实用且经济**：完整的双臂系统售价 6,500 美元，OpenArm 以传统人形机器人成本的一小部分提供研究级能力。

## 平台要求[[platform-requirements]]

<Tip warning={true}>
  **仅限 Linux**：OpenArm 目前仅在 Linux 上运行。CAN 总线 USB 适配器 没有 macOS
  驱动，也尚未在 Windows 上测试。
</Tip>

## 安全指南[[safety-guide]]

在操作 OpenArm 之前，请阅读[官方安全指南](https://docs.openarm.dev/getting-started/safety-guide)。要点：

- **牢固安装**：使用螺丝或夹具将机械臂固定到平坦、稳定的表面上
- **安全距离**：操作期间，使身体部位和物体保持在运动范围之外
- **防护装备**：始终佩戴护目镜；根据需要穿戴其他个人防护装备（PPE）
- **有效载荷限制**：不要超过规定的有效载荷限制（每臂峰值 6.0kg / 额定 4.1kg）
- **急停**：了解急停装置的位置和操作方法
- **定期检查**：检查螺丝是否松动、机械限位是否损坏、是否有异常噪音以及接线是否损坏

## 硬件设置[[hardware-setup]]

请遵循官方 [OpenArm 硬件文档](https://docs.openarm.dev) 完成以下事项：

- 物料清单与采购

硬件仓库位于 [github.com/enactic/openarm](https://github.com/enactic/openarm)。

## CAN 总线设置[[can-bus-setup]]

OpenArm 使用 CAN 总线与 Damiao 电机通信。将 CAN 总线 USB 适配器插入 Linux PC 后，请按照 [Damiao 电机与 CAN 总线指南](./damiao) 配置接口。

快速设置：

```bash
# 设置 CAN 接口
lerobot-setup-can --mode=setup --interfaces=can0,can1

# 测试电机通信
lerobot-setup-can --mode=test --interfaces=can0,can1
```

## 安装 LeRobot 🤗[[install-lerobot-]]

请遵循我们的[安装指南](./installation)，然后安装 Damiao 电机支持：

```bash
pip install -e ".[damiao]"
```

## 使用[[usage]]

### 从臂（机器人）[[follower-arm-robot]]

<hfoptions id="follower">
<hfoption id="命令">

```bash
lerobot-calibrate \
    --robot.type=openarm_follower \
    --robot.port=can0 \
    --robot.side=right \
    --robot.id=my_openarm_follower
```

</hfoption>
<hfoption id="API 示例">

```python
from lerobot.robots.openarm_follower import OpenArmFollower, OpenArmFollowerConfig

config = OpenArmFollowerConfig(
    port="can0",
    side="right",  # 或 "left" 表示左臂
    id="my_openarm_follower",
)

follower = OpenArmFollower(config)
follower.connect()

# 读取当前状态
obs = follower.get_observation()
print(obs)

# 发送动作（位置以度为单位）
action = {
    "joint_1.pos": 0.0,
    "joint_2.pos": 0.0,
    "joint_3.pos": 0.0,
    "joint_4.pos": 45.0,
    "joint_5.pos": 0.0,
    "joint_6.pos": 0.0,
    "joint_7.pos": 0.0,
    "gripper.pos": 0.0,
}
follower.send_action(action)

follower.disconnect()
```

</hfoption>
</hfoptions>

### 主臂（遥操作器）[[leader-arm-teleoperator]]

主臂用于遥操作——手动移动它以控制从臂。

<hfoptions id="leader">
<hfoption id="命令">

```bash
lerobot-calibrate \
    --teleop.type=openarm_leader \
    --teleop.port=can1 \
    --teleop.id=my_openarm_leader
```

</hfoption>
<hfoption id="API 示例">

```python
from lerobot.teleoperators.openarm_leader import OpenArmLeader, OpenArmLeaderConfig

config = OpenArmLeaderConfig(
    port="can1",
    id="my_openarm_leader",
    manual_control=True,  # 手动移动时禁用扭矩
)

leader = OpenArmLeader(config)
leader.connect()

# 读取当前位置（作为发送给从臂的动作）
action = leader.get_action()
print(action)

leader.disconnect()
```

</hfoption>
</hfoptions>

### 遥操作[[teleoperation]]

要使用主从控制遥操作 OpenArm：

```bash
lerobot-teleoperate \
    --robot.type=openarm_follower \
    --robot.port=can0 \
    --robot.side=right \
    --robot.id=my_follower \
    --teleop.type=openarm_leader \
    --teleop.port=can1 \
    --teleop.id=my_leader
```

### 双臂遥操作[[bimanual-teleoperation]]

要遥操作包含两个主臂和两个从臂的双臂 OpenArm 设置：

```bash
lerobot-teleoperate \
    --robot.type=bi_openarm_follower \
    --robot.left_arm_config.port=can0 \
    --robot.left_arm_config.side=left \
    --robot.right_arm_config.port=can1 \
    --robot.right_arm_config.side=right \
    --robot.id=my_bimanual_follower \
    --teleop.type=bi_openarm_leader \
    --teleop.left_arm_config.port=can2 \
    --teleop.right_arm_config.port=can3 \
    --teleop.id=my_bimanual_leader
```

### 记录数据[[recording-data]]

要在遥操作期间记录数据集：

```bash
lerobot-record \
    --robot.type=openarm_follower \
    --robot.port=can0 \
    --robot.side=right \
    --robot.id=my_follower \
    --teleop.type=openarm_leader \
    --teleop.port=can1 \
    --teleop.id=my_leader \
    --repo-id=my_hf_username/my_openarm_dataset \
    --fps=30 \
    --num-episodes=10
```

## 配置选项[[configuration-options]]

### 从臂配置[[follower-configuration]]

| 参数                  | 默认值    | 描述                                                    |
| --------------------- | --------- | ------------------------------------------------------- |
| `port`                | -         | CAN 接口（例如 `can0`）                                 |
| `side`                | `None`    | 机械臂侧：`"left"`、`"right"`，或 `None` 表示自定义限位 |
| `use_can_fd`          | `True`    | 启用 CAN FD 以获得更高数据速率                          |
| `can_bitrate`         | `1000000` | 标称比特率（1 Mbps）                                    |
| `can_data_bitrate`    | `5000000` | CAN FD 数据比特率（5 Mbps）                             |
| `max_relative_target` | `None`    | 相对目标位置的安全限制                                  |
| `position_kp`         | 每个关节  | 位置控制比例增益                                        |
| `position_kd`         | 每个关节  | 位置控制微分增益                                        |

### 主臂配置[[leader-configuration]]

| 参数               | 默认值    | 描述                           |
| ------------------ | --------- | ------------------------------ |
| `port`             | -         | CAN 接口（例如 `can1`）        |
| `manual_control`   | `True`    | 手动移动时禁用扭矩             |
| `use_can_fd`       | `True`    | 启用 CAN FD 以获得更高数据速率 |
| `can_bitrate`      | `1000000` | 标称比特率（1 Mbps）           |
| `can_data_bitrate` | `5000000` | CAN FD 数据比特率（5 Mbps）    |

## 电机配置[[motor-configuration]]

OpenArm 使用 Damiao 电机，默认配置如下：

| 关节                    | 电机类型 | 发送 ID | 接收 ID |
| ----------------------- | -------- | ------- | ------- |
| joint_1（肩部水平旋转） | DM8009   | 0x01    | 0x11    |
| joint_2（肩部抬升）     | DM8009   | 0x02    | 0x12    |
| joint_3（肩部旋转）     | DM4340   | 0x03    | 0x13    |
| joint_4（肘部弯曲）     | DM4340   | 0x04    | 0x14    |
| joint_5（腕部滚转）     | DM4310   | 0x05    | 0x15    |
| joint_6（腕部俯仰）     | DM4310   | 0x06    | 0x16    |
| joint_7（腕部旋转）     | DM4310   | 0x07    | 0x17    |
| gripper（夹爪）         | DM4310   | 0x08    | 0x18    |

## 故障排除[[troubleshooting]]

### 电机无响应[[no-response-from-motors]]

1. 检查电源连接
2. 验证 CAN 接线（CAN-H、CAN-L、GND）
3. 运行诊断：`lerobot-setup-can --mode=test --interfaces=can0`
4. 更多详情请参阅 [Damiao 故障排除指南](./damiao#troubleshooting)

### 找不到 CAN 接口[[can-interface-not-found]]

确保已配置 CAN 接口：

```bash
ip link show can0
```
