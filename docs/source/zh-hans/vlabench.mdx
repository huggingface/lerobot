# VLABench[[vlabench]]

[VLABench](https://github.com/OpenMOSS/VLABench) 是一个大规模基准（benchmark），用于**语言条件机器人操作与长时程推理**。上游套件（upstream suite）覆盖 100 个任务类别、2,000+ 个对象，并评估机器人智能的六个维度：网格与纹理理解、空间推理、世界知识迁移、语义指令理解、物理定律理解以及长时程规划。它基于 MuJoCo / dm_control 构建，使用 Franka Panda 7-DOF 机械臂。LeRobot 通过 `--env.task` 提供**其中 43 个任务**：21 个基元任务（primitive）+ 22 个复合任务（composite），见下方[可用任务](#available-tasks)。

- 论文：[VLABench：面向语言条件机器人操作与长时程推理的大规模基准](https://arxiv.org/abs/2412.18194)
- GitHub：[OpenMOSS/VLABench](https://github.com/OpenMOSS/VLABench)
- 项目网站：[vlabench.github.io](https://vlabench.github.io)
- 预训练策略（policy）：[`lerobot/smolvla_vlabench`](https://huggingface.co/lerobot/smolvla_vlabench)

## 可用任务[[available-tasks]]

VLABench 提供两个任务套件（task suite），涵盖 LeRobot `--env.task` 接口中的 **43 个任务类别**：

| 套件 | CLI 名称    | 任务数 | 描述                                        |
| ---- | ----------- | ------ | ------------------------------------------- |
| 基元 | `primitive` | 21     | 单技能 / 少技能组合（选择、插入、物理问答） |
| 复合 | `composite` | 22     | 多步推理与长时程规划（烹饪、重新排列）      |

**基元任务：** `select_fruit`、`select_toy`、`select_chemistry_tube`、`add_condiment`、`select_book`、`select_painting`、`select_drink`、`insert_flower`、`select_billiards`、`select_ingredient`、`select_mahjong`、`select_poker`，以及物理推理任务（`density_qa`、`friction_qa`、`magnetism_qa`、`reflection_qa`、`simple_cuestick_usage`、`simple_seesaw_usage`、`sound_speed_qa`、`thermal_expansion_qa`、`weight_qa`）。

**复合任务：** `cluster_billiards`、`cluster_book`、`cluster_drink`、`cluster_toy`、`cook_dishes`、`cool_drink`、`find_unseen_object`、`get_coffee`、`hammer_nail`、`heat_food`、`make_juice`、`play_mahjong`、`play_math_game`、`play_poker`、`play_snooker`、`rearrange_book`、`rearrange_chemistry_tube`、`set_dining_table`、`set_study_table`、`store_food`、`take_chemistry_experiment`、`use_seesaw_complex`。

`--env.task` 接受三种形式：

- 单个任务名称（`select_fruit`）
- 逗号分隔列表（`select_fruit,heat_food`）
- 套件快捷方式（suite shortcut），例如 `primitive`、`composite` 或 `primitive,composite`

## 安装[[installation]]

VLABench **不在 PyPI 上**——其唯一分发渠道是 [OpenMOSS/VLABench](https://github.com/OpenMOSS/VLABench) GitHub 仓库——因此 LeRobot 不提供 `vlabench` 额外安装项（extra）。请将其作为可编辑克隆（editable clone）手动安装，并搭配 VLABench 所需的 MuJoCo / dm_control 固定版本（pin），然后获取网格资产（mesh asset）：

```bash
# 在按照标准 LeRobot 安装说明操作之后。

git clone https://github.com/OpenMOSS/VLABench.git ~/VLABench
git clone https://github.com/motion-planning/rrt-algorithms.git ~/rrt-algorithms
pip install -e ~/VLABench -e ~/rrt-algorithms
pip install "mujoco==3.2.2" "dm-control==1.0.22" \
            open3d colorlog scikit-learn openai gdown

python ~/VLABench/scripts/download_assets.py
```

<Tip>
VLABench 需要 Linux（`sys_platform == 'linux'`）和 Python 3.10+。在运行前设置 MuJoCo 渲染后端（rendering backend）：

```bash
export MUJOCO_GL=egl  # 用于无头服务器（HPC、云）
```

</Tip>

## 评估[[evaluation]]

下方所有评估代码片段（eval snippet）均与 CI 运行的命令一致（见 `.github/workflows/benchmark_tests.yml`）。`--rename_map` 参数将 VLABench 的 `image` / `second_image` / `wrist_image` 相机键（camera key）映射到已发布的 `smolvla_vlabench` 策略（policy）训练时所用的三相机（`camera1` / `camera2` / `camera3`）输入布局（input layout）。

### 单任务评估（推荐用于快速迭代）[[single-task-evaluation-recommended-for-quick-iteration]]

```bash
lerobot-eval \
  --policy.path=lerobot/smolvla_vlabench \
  --env.type=vlabench \
  --env.task=select_fruit \
  --eval.batch_size=1 \
  --eval.n_episodes=10 \
  --eval.use_async_envs=false \
  --policy.device=cuda \
  '--rename_map={"observation.images.image": "observation.images.camera1", "observation.images.second_image": "observation.images.camera2", "observation.images.wrist_image": "observation.images.camera3"}'
```

### 多任务评估[[multi-task-evaluation]]

传入逗号分隔的任务列表：

```bash
lerobot-eval \
  --policy.path=lerobot/smolvla_vlabench \
  --env.type=vlabench \
  --env.task=select_fruit,select_toy,add_condiment,heat_food \
  --eval.batch_size=1 \
  --eval.n_episodes=10 \
  --eval.use_async_envs=false \
  --policy.device=cuda \
  '--rename_map={"observation.images.image": "observation.images.camera1", "observation.images.second_image": "observation.images.camera2", "observation.images.wrist_image": "observation.images.camera3"}'
```

### 套件级评估[[suite-wide-evaluation]]

运行整个套件（全部 21 个基元任务或全部 22 个复合任务）：

```bash
lerobot-eval \
  --policy.path=lerobot/smolvla_vlabench \
  --env.type=vlabench \
  --env.task=primitive \
  --eval.batch_size=1 \
  --eval.n_episodes=10 \
  --eval.use_async_envs=false \
  --policy.device=cuda \
  --env.max_parallel_tasks=1 \
  '--rename_map={"observation.images.image": "observation.images.camera1", "observation.images.second_image": "observation.images.camera2", "observation.images.wrist_image": "observation.images.camera3"}'
```

或同时运行两个套件：

```bash
lerobot-eval \
  --policy.path=lerobot/smolvla_vlabench \
  --env.type=vlabench \
  --env.task=primitive,composite \
  --eval.batch_size=1 \
  --eval.n_episodes=10 \
  --eval.use_async_envs=false \
  --policy.device=cuda \
  --env.max_parallel_tasks=1 \
  '--rename_map={"observation.images.image": "observation.images.camera1", "observation.images.second_image": "observation.images.camera2", "observation.images.wrist_image": "observation.images.camera3"}'
```

### 推荐的评估回合数[[recommended-evaluation-episodes]]

**每个任务 10 个回合**（episode），以实现可复现的基准测试（reproducible benchmarking）：完整基元套件共 210 个回合，复合套件 220 个回合。与 VLABench 论文中的协议（protocol）一致。

## 策略输入与输出[[policy-inputs-and-outputs]]

**观测**（observation）：

- `observation.state` —— 7 维末端执行器（end effector）状态，包含位置 xyz + 欧拉角 xyz + 夹爪（gripper）
- `observation.images.image` —— 前相机，480×480 HWC uint8
- `observation.images.second_image` —— 第二相机，480×480 HWC uint8
- `observation.images.wrist_image` —— 腕部相机，480×480 HWC uint8

**动作**（action）：

- `Box(-1, 1, shape=(7,))` 中的连续控制 —— 3D 位置 + 3D 欧拉朝向 + 1D 夹爪。

## 训练[[training]]

### 数据集[[datasets]]

Hub 上采用 LeRobot 格式的预收集 VLABench 数据集（dataset）：

- [`VLABench/vlabench_primitive_ft_lerobot_video`](https://huggingface.co/datasets/VLABench/vlabench_primitive_ft_lerobot_video) —— 5,000 个回合（episode），128 个任务，480×480 图像。
- [`VLABench/vlabench_composite_ft_lerobot_video`](https://huggingface.co/datasets/VLABench/vlabench_composite_ft_lerobot_video) —— 5,977 个回合，167 个任务，224×224 图像。

### 示例训练命令[[example-training-command]]

在基元套件上微调 SmolVLA 基础模型：

```bash
lerobot-train \
  --policy.type=smolvla \
  --policy.repo_id=${HF_USER}/smolvla_vlabench_primitive \
  --policy.load_vlm_weights=true \
  --policy.push_to_hub=true \
  --dataset.repo_id=VLABench/vlabench_primitive_ft_lerobot_video \
  --env.type=vlabench \
  --env.task=select_fruit \
  --output_dir=./outputs/smolvla_vlabench_primitive \
  --steps=100000 \
  --batch_size=4 \
  --env_eval_freq=5000 \
  --eval.batch_size=1 \
  --eval.n_episodes=1 \
  --save_freq=10000
```

## 复现已发表结果[[reproducing-published-results]]

已发布的检查点（checkpoint）[`lerobot/smolvla_vlabench`](https://huggingface.co/lerobot/smolvla_vlabench) 是在上述基元套件数据集上训练的，并使用[单任务](#single-task-evaluation-recommended-for-quick-iteration) / [套件级](#suite-wide-evaluation)命令进行评估。CI 会在每个涉及该基准的 PR 上运行一个包含 10 个基元任务的冒烟评估（smoke eval），每个任务一个回合（episode）。
