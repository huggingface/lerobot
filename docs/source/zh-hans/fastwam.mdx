# FastWAM[[fastwam]]

FastWAM 是一种用于机器人控制的世界动作模型（World Action Model）策略。LeRobot 集成通过标准策略 API 公开 FastWAM，因此可以使用 `policy.type=fastwam` 对其进行配置、使用 `lerobot-train` 进行训练，并通过 LeRobot 预训练策略接口加载。

## Model Overview[[model-overview]]

FastWAM 在训练期间保留视频建模，但在推理时采用直接动作预测，而不是迭代地生成未来观测（observation）。该 LeRobot 策略封装了 FastWAM 动作模型，将 LeRobot 批次适配为 FastWAM 训练样本，并提供用于归一化和动作后处理的标准处理器流水线。

The implementation initializes the visual world-model components from `Wan-AI/Wan2.2-TI2V-5B` by default and predicts action chunks with shape `[batch, action_horizon, action_dim]`.

### What the LeRobot Integration Covers[[what-the-lerobot-integration-covers]]

- 通过 LeRobot 进行标准的 `policy.type=fastwam` 配置
- 图像、状态、动作和语言任务批次适配
- 通过 `select_action` 和 `predict_action_chunk` 进行动作块推理
- 通过 LeRobot 策略 API 保存/加载检查点
- 可配置的 LIBERO 夹爪动作后处理

## Installation Requirements[[installation-requirements]]

从源码安装 LeRobot，然后安装 FastWAM 依赖项：

```bash
pip install -e ".[fastwam]"
```

这会从 `pyproject.toml` 安装 FastWAM 策略 extra：`transformers`、
`diffusers`、`ftfy` 和 `regex`，以及 LeRobot 的基础依赖项。

如需进行 LIBERO 评测，还要安装基准（benchmark）依赖项：

```bash
pip install -e ".[fastwam,libero]"
```

这会同时安装两个 extra。除了上述 FastWAM 依赖项之外，
`libero` extra 还会安装 LeRobot 数据集依赖项、Linux 上的 `hf-libero`，以及
`scipy`。

FastWAM 使用 Wan2.2 TI2V 主干网络。默认模型 ID 为：

```python
policy.model_id=Wan-AI/Wan2.2-TI2V-5B
```

## Data Requirements[[data-requirements]]

FastWAM 要求 LeRobot 数据集包含：

- 一个或多个视觉观测（observation），其宽度拼接后等于 `policy.image_size[1]`
- 当 `policy.proprio_dim` 不为 `None` 时提供 `observation.state`
- `action`
- 通过数据集任务字段提供的语言任务指令，或预计算的 `context` 和 `context_mask` 张量

默认的视觉设置为一个名为 `observation.images.image` 的图像特征，其形状为 `(3, 224, 448)`。如果数据集使用两个相机，请配置 `policy.input_features`，使其高度均为 `224`，且宽度之和为 `448`。

## Usage[[usage]]

使用以下命令创建新的 FastWAM 策略：

```bash
lerobot-train \
  --dataset.repo_id=your-org/your-dataset \
  --policy.type=fastwam \
  --policy.action_dim=7 \
  --policy.proprio_dim=8 \
  --policy.action_horizon=32 \
  --policy.n_action_steps=10 \
  --policy.image_size='[224,448]' \
  --output_dir=./outputs/fastwam_training \
  --job_name=fastwam_training \
  --steps=300000 \
  --batch_size=8 \
  --policy.device=cuda
```

使用以下命令在 LIBERO-10 上评测现有的 LeRobot 格式检查点：

```bash
lerobot-eval \
  --policy.path=ZibinDong/fastwam_libero_uncond_2cam224 \
  --policy.device=cuda \
  --policy.dtype=float32 \
  --policy.n_action_steps=10 \
  --env.type=libero \
  --env.task=libero_10 \
  --env.observation_height=224 \
  --env.observation_width=224 \
  --eval.batch_size=1 \
  --eval.n_episodes=50 \
  --seed=0 \
  --env.episode_length=600
```

对于 `libero_goal`、`libero_spatial` 和 `libero_object`，请使用
`--env.episode_length=300`。

对于真机 rollout，请使用相同的检查点路径：

```bash
lerobot-rollout \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyACM0 \
  --policy.path=your-org/fastwam-real-robot
```

## Configuration Notes[[configuration-notes]]

### Image Features[[image-features]]

`policy.image_size` 是拼接后的 FastWAM 图像张量的大小，表示为 `(height, width)`。每个配置的图像特征必须具有形状 `(3, height, camera_width)`，且所有相机宽度之和必须等于所配置的宽度。

### Action Chunking[[action-chunking]]

`policy.action_horizon` 控制在训练期间被监督、在推理期间被预测的未来动作数量。`policy.n_action_steps` 控制在该策略预测新动作块之前会消耗多少个动作。`policy.n_action_steps` 必须小于或等于 `policy.action_horizon`。

### Wan Components[[wan-components]]

FastWAM 从所配置的 Wan 模型目录或 Hugging Face Hub 模型 ID 加载 Wan VAE、视频 DiT、文本编码器和分词器。由 `save_pretrained` 保存的 LeRobot 格式 FastWAM 检查点也会复制 `from_pretrained` 所需的本地 Wan 组件文件。

### Attention Backend[[attention-backend]]

FastWAM 的 DiT 对所有注意力都使用 PyTorch 的 `scaled_dot_product_attention`（SDPA）。它**不**使用 FlashAttention：其混合 Transformer（Mixture-of-Transformers，MoT）路由需要任意的布尔 `[query, key]` 注意力掩码，而 FlashAttention 的 varlen API 无法表达这种掩码。因此，安装 `flash-attn` 包对 FastWAM 路径没有影响。（请注意，SDPA 本身在内部仍可能选择 PyTorch 自带的 flash / memory-efficient / math 内核——这与 `flash-attn` 包无关。）

### Compiled Action Inference[[compiled-action-inference]]

FastWAM 可以编译其视频预填充（video-prefill）图与缓存的动作去噪（action-denoising）图，以减少
重复推理步骤中的 Python 和 CUDA 内核启动开销：

```bash
--policy.compile_action_infer=true
```

该选项默认关闭。首次动作预测会针对当前输入形状编译计算图
，因此速度较慢；之后具有相同形状的预测会复用它。形状变化可能触发重新编译。在不支持的 PyTorch 或加速器配置上，
仍可使用 eager 路径。

### LIBERO Action Toggle[[libero-action-toggle]]

FastWAM LIBERO 检查点默认使用 `policy.toggle_action_dimensions=[-1]`，
以匹配原始 FastWAM 评测流水线所使用的夹爪动作约定：

```bash
--policy.toggle_action_dimensions='[-1]'
```

## Results[[results]]

在 LIBERO 上使用 [`ZibinDong/fastwam_libero_uncond_2cam224`](https://huggingface.co/ZibinDong/fastwam_libero_uncond_2cam224) 进行评测：

| 套件           |    成功率 | n_episodes |
| -------------- | --------: | ---------: |
| libero_spatial |     97.6% |        500 |
| libero_object  |     99.0% |        500 |
| libero_goal    |     95.0% |        500 |
| libero_10      |     94.0% |        500 |
| **平均值**     | **96.4%** |       2000 |

复现：`lerobot-eval --policy.path=ZibinDong/fastwam_libero_uncond_2cam224 --policy.device=cuda --policy.dtype=float32 --policy.n_action_steps=10 --env.type=libero --env.task=libero_spatial --env.observation_height=256 --env.observation_width=256 --eval.batch_size=1 --eval.n_episodes=50 --seed=0 --env.episode_length=300`（1x H20 140 GB）。
