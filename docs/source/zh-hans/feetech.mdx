# 升级飞特舵机固件[[feetech-motor-firmware-update]]

这篇教程将会指导你使用飞特官方软件升级飞特舵机的固件。

## 前置要求[[prerequisites]]

- Windows 电脑（飞特软件仅在 Windows 上可用）
- 飞特舵机控制板
- 用于连接控制板与电脑的 USB 线
- 已连接到控制板的飞特舵机

## 步骤 1：下载飞特软件[[step-1-download-feetech-software]]

1. 访问飞特官方软件下载页面：[https://www.feetechrc.com/software.html](https://www.feetechrc.com/software.html)
2. 下载最新版本的飞特调试软件（FD）
3. 将软件安装到你的 Windows 电脑上

## 步骤 2：硬件设置[[step-2-hardware-setup]]

1. 将飞特舵机连接到舵机控制板
2. 通过 USB 线将舵机控制板连接到 Windows 电脑
3. 确保为舵机供电

## 步骤 3：配置连接[[step-3-configure-connection]]

1. 启动飞特调试软件
2. 从端口下拉菜单中选择正确的 COM 端口
   - 如果不确定使用哪个端口，请在 Windows 设备管理器的“端口（COM & LPT）”下查看
3. 设置合适的波特率（对于大多数飞特舵机，通常为 1000000）
4. 点击“打开”以与控制板建立通信

## 步骤 4：搜索舵机[[step-4-scan-for-motors]]

1. 连接后，点击“搜索”按钮以检测所有已连接的舵机
2. 软件会自动发现并列出总线上的所有舵机
3. 每个舵机将显示其 ID 号

## 步骤 5：更新固件[[step-5-update-firmware]]

对于每个要更新的舵机：

1. **选择舵机**：在列表中点击它
2. **点击“升级”选项卡**：
3. **点击“在线”按钮**：
   - 如果发现可能的固件更新，它将显示在框中
4. **点击“升级”按钮**：
   - 将显示更新进度

## 步骤 6：验证更新[[step-6-verify-update]]

1. 更新完成后，软件应自动刷新舵机信息
2. 确认固件版本已更新到预期版本

## 注意事项[[important-notes]]

⚠️ **警告**：固件更新期间请勿断开电源或 USB，否则可能会使舵机变砖。

## 奖励：在 Linux/macOS 上调试舵机[[bonus-motor-debugging-on-linuxmacos]]

仅用于调试目的，你可以使用开源的 Feetech 调试工具：

- **代码仓库**：[FT_SCServo_Debug_Qt](https://github.com/CarolinePascal/FT_SCServo_Debug_Qt/tree/fix/port-search-timer)

### 安装说明[[installation-instructions]]

请按照代码仓库中的说明安装该工具。对于 Ubuntu，可以直接安装；对于 MacOS，需要从源代码构建。

**限制：**

- 此工具仅用于调试和参数调整
- 固件更新仍必须在 Windows 上使用官方 Feetech 软件完成
