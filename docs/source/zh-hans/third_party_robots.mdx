# 第三方机器人与遥操作器[[third-party-robots-teleoperators]]

LeRobot 生态系统远不止其官方支持的硬件。得益于 LeRobot 的插件架构，社区已为各种机械臂和遥操作（teleoperation）设备构建了集成——从工业机械臂到价格亲民的爱好者平台、VR 头显、触觉设备，以及完整的机械臂加遥操作器套件。本页展示了社区维护的集成，可用于遥操作、数据采集和策略（policy）部署。

> [!IMPORTANT]
> 这些项目由第三方开发和维护。请参阅各个代码仓库以获取安装说明、硬件要求和支持信息。

即插即用插件会按包名自动发现：LeRobot 会导入任何已安装且以 `lerobot_robot_` 或 `lerobot_teleoperator_` 为前缀的包。安装后，可直接在任意 LeRobot 命令中引用插件注册的 `type`（参见其 README——它可能与包名不同）：

```bash
pip install lerobot_robot_<name> lerobot_teleoperator_<name>

lerobot-record \
    --robot.type=<robot_name> \
    --teleop.type=<teleoperator_name> \
    --dataset.repo_id=${HF_USER}/my-dataset \
    --dataset.num_episodes=5
```

> [!TIP]
> ⚠️ 标记的是 LeRobot 的分支/扩展项目。它们可能需要自定义设置，而不能在未修改的安装环境中直接使用。其他所有条目均为即插即用插件。
