**面向现实世界机器人的最先进的机器学习技术**

🤗 LeRobot 提供了硬件无关、原生 Python 的接口，用于控制真实机器人——从 SO-ARM101 这样经济实惠的机械臂到完整的类人机器人。此外还提供录制、存储和分享它们所生成数据集的工具。每个数据集都使用标准化的 **LeRobotDataset** 格式（同步的视频 + 动作/状态数据），并且可以直接从 [Hugging Face Hub](https://huggingface.co/lerobot) 流式加载。

🤗 在这些数据之上，LeRobot 实现了最先进的策略（policy）——从 ACT 这样的轻量级模仿学习模型，到 π₀ 和 SmolVLA 这样的大型视觉-语言-动作模型——它们都可以通过同样少数几条 CLI 命令来训练、分享和部署。

目标：降低机器人技术的准入门槛，让每个人都能为共享数据集和预训练模型做出贡献，并从中受益。

## 工作原理[[how-it-works]]

**遥操作 → 录制 → 训练 → 部署**

1. **遥操作**（Teleoperate）——自己使用主臂（leader arm）、键盘或手机来控制机器人，让它从你的动作中学习。
2. **录制**（Record）——每次演示都会保存为一个数据集：同步的摄像头视频，加上你所执行的动作。
3. **训练**（Train）——策略（policy，也就是将来控制机器人的神经网络）会学习模仿你的演示。
4. **部署**（Deploy）——在机器人上运行训练好的策略，看它自行完成任务。

## 常见问题[[common-problems]]

遇到问题了？以下是几个最常见的问题：

- **摄像头画面模糊或不可用**——光照比分辨率更重要。请参阅[摄像头](./cameras)指南。
- **构建或安装错误**（`cmake`、`ffmpeg`、CUDA）——请参阅[安装指南](./installation#troubleshooting)的故障排除部分。
- **不确定哪种策略适合你的 GPU**——请查看[计算与硬件指南](./hardware_guide)。
- **还是卡住了？** 在 [Discord](https://discord.gg/s3KuuzsPFb) 上提问——社区（以及 LeRobot 团队）随时提供帮助。
