**用于现实世界机器人的最先进机器学习**

🤗 LeRobot 提供了一个硬件无关、Python 原生的接口来控制真实机器人——从价格实惠的 SO-ARM101 机械臂到完整的人形机器人。此外，还提供了记录、存储和分享它们生成的数据集的工具。每个数据集都使用标准化的 **LeRobotDataset** 格式（同步视频 + 动作/状态数据），可以直接从 [Hugging Face Hub](https://huggingface.co/lerobot) 流式传输。

🤗 基于这些数据，LeRobot 实现了最先进的策略——从轻量级的模仿学习模型如 ACT，到大型视觉 - 语言 - 动作模型如 π₀ 和 SmolVLA——所有这些都可以通过少量 CLI 命令进行训练、分享和部署。

目标：降低机器人技术的入门门槛，让每个人都能贡献并受益于共享数据集和预训练模型。

## 工作原理

**遥操作 → 记录 → 训练 → 部署**

1. **遥操作** - 自己控制机器人（使用主臂、键盘或手机），让它从你的动作中学习。
2. **记录** - 每次演示都保存为一个数据集：同步的摄像头视频和你执行的动作。
3. **训练** - 策略（控制机器人的神经网络）学习模仿你的演示。
4. **部署** - 在机器人上运行训练好的策略，看着它独立完成任务。

## 常见问题

遇到问题？以下是一些最常见的情况：

- **摄像头画面模糊或无法使用** - 光线比分辨率更重要。查看 [摄像头](./cameras) 指南。
- **构建或安装错误**（`cmake`、`ffmpeg`、CUDA）- 查看 [安装指南](./installation#troubleshooting) 的故障排除部分。
- **不确定哪个策略适合你的 GPU** - 查看 [计算与硬件指南](./hardware_guide)。
- **仍然卡住？** 在 [Discord](https://discord.gg/s3KuuzsPFb) 上提问——社区（和 LeRobot 团队）在那里提供帮助。
