# LIBERO-plus[[libero-plus]]

LIBERO-plus 是一个基于 [LIBERO](./libero) 构建的**鲁棒性基准**，面向视觉-语言-动作（Vision-Language-Action，VLA）模型。它通过对原始 LIBERO 任务集施加**七个相互独立的扰动维度**，系统性地对策略（policy）进行压力测试，从而暴露出标准基准所遗漏的失效模式。

- 论文：[In-depth Robustness Analysis of Vision-Language-Action Models](https://arxiv.org/abs/2510.13626)
- GitHub：[sylvestf/LIBERO-plus](https://github.com/sylvestf/LIBERO-plus)
- 数据集：[lerobot/libero_plus](https://huggingface.co/datasets/lerobot/libero_plus)

![LIBERO-plus 基准扰动维度概览](https://github.com/sylvestf/LIBERO-plus/raw/main/static/images/libero-plus.jpg)

## 扰动维度[[perturbation-dimensions]]

LIBERO-plus 沿这些维度对每个原始 LIBERO 任务进行扰动，生成了约 10 000 个任务变体：

| 维度           | 变化内容                                |
| -------------- | --------------------------------------- |
| 物体布局       | 目标位置、是否存在干扰物体              |
| 相机视角       | 相机位置、朝向、视场                    |
| 机器人初始状态 | 机械臂起始位姿                          |
| 语言指令       | 由 LLM 重写的任务描述（改写／同义替换） |
| 光照条件       | 强度、方向、颜色、阴影                  |
| 背景纹理       | 场景表面与物体外观                      |
| 传感器噪声     | 光度畸变与图像退化                      |

## 可用的任务套件[[available-task-suites]]

LIBERO-plus 覆盖与 LIBERO 相同的五个套件：

| 套件           | CLI 名称         | 任务数 | 最大步数 | 说明                             |
| -------------- | ---------------- | ------ | -------- | -------------------------------- |
| LIBERO-Spatial | `libero_spatial` | 10     | 280      | 需要对空间关系进行推理的任务     |
| LIBERO-Object  | `libero_object`  | 10     | 280      | 以操作不同物体为核心的任务       |
| LIBERO-Goal    | `libero_goal`    | 10     | 300      | 目标不断变化的目标条件任务       |
| LIBERO-90      | `libero_90`      | 90     | 400      | 来自 LIBERO-100 集合的短时程任务 |
| LIBERO-Long    | `libero_10`      | 10     | 520      | 来自 LIBERO-100 集合的长时程任务 |

<Tip warning={true}>
  安装 LIBERO-plus 会**替换**原版 LIBERO——它会卸载 `hf-libero`， 使 `import
  libero` 解析到 LIBERO-plus 分支。两者无法同时安装。 若要切回原版
  LIBERO，请卸载该分支并重新执行 `pip install -e ".[libero]"`。
</Tip>

## 安装[[installation]]

### 系统依赖（仅限 Linux）[[system-dependencies-linux-only]]

```bash
sudo apt install libexpat1 libfontconfig1-dev libmagickwand-dev
```

### Python 包[[python-package]]

```bash
pip install -e ".[libero]" "robosuite==1.4.1" bddl easydict mujoco wand scikit-image gym
git clone https://github.com/sylvestf/LIBERO-plus.git
cd LIBERO-plus && pip install --no-deps -e .
pip uninstall -y hf-libero  # 使 `import libero` 解析到该分支
```

LIBERO-plus 不是通过 pyproject extra 安装，而是从其 GitHub 分支安装——该分支以命名空间包的形式发布，pip 无法处理，因此必须克隆后加入 `PYTHONPATH`。规范的安装方式参见 `docker/Dockerfile.benchmark.libero_plus`。由于依赖 MuJoCo，因此仅支持 Linux。

<Tip>
在运行评估前设置 MuJoCo 渲染后端：

```bash
export MUJOCO_GL=egl   # 无头模式 / HPC / 云端
```

</Tip>

### 下载 LIBERO-plus 资源[[download-libero-plus-assets]]

LIBERO-plus 的扩展资源包是单独发布的。请从 [Hugging Face 数据集](https://huggingface.co/datasets/Sylvest/LIBERO-plus/tree/main)下载 `assets.zip`，并将其解压到 LIBERO-plus 包目录中：

```bash
# 安装好包之后，找到它的安装位置：
python -c "import libero; print(libero.__file__)"
# 然后把 assets.zip 解压到 <package_root>/libero/assets/
```

## 评估[[evaluation]]

### 默认评估（推荐）[[default-evaluation-recommended]]

在四个标准套件上进行评估（每个任务 10 个片段）：

```bash
lerobot-eval \
  --policy.path="your-policy-id" \
  --env.type=libero_plus \
  --env.task=libero_spatial,libero_object,libero_goal,libero_10 \
  --eval.batch_size=1 \
  --eval.n_episodes=10 \
  --env.max_parallel_tasks=1
```

### 单套件评估[[single-suite-evaluation]]

在单个 LIBERO-plus 套件上评估：

```bash
lerobot-eval \
  --policy.path="your-policy-id" \
  --env.type=libero_plus \
  --env.task=libero_spatial \
  --eval.batch_size=1 \
  --eval.n_episodes=10
```

- `--env.task` 指定套件（`libero_spatial`、`libero_object` 等）。
- `--env.task_ids` 限定为特定的任务索引（`[0]`、`[1,2,3]` 等）。省略则运行套件中的所有任务。
- `--eval.batch_size` 控制同时运行的环境数量。
- `--eval.n_episodes` 设置每个任务运行的片段数。

### 多套件评估[[multi-suite-evaluation]]

传入以逗号分隔的列表，即可一次性在多个套件上对策略进行基准测试：

```bash
lerobot-eval \
  --policy.path="your-policy-id" \
  --env.type=libero_plus \
  --env.task=libero_spatial,libero_object \
  --eval.batch_size=1 \
  --eval.n_episodes=10
```

### 控制模式[[control-mode]]

LIBERO-plus 支持两种控制模式——`relative`（默认）和 `absolute`。不同的 VLA 检查点使用不同的动作参数化方式训练，因此请确保所选模式与你的策略（policy）匹配：

```bash
--env.control_mode=relative   # 或 "absolute"
```

### 重置性能[[reset-performance]]

默认情况下，LeRobot 保留 LIBERO 的硬重置行为。在启用固定初始状态的前提下，你可以选择使用软重置，以跳过在每个片段重建仿真器模型和渲染器：

```bash
--env.init_states=true --env.hard_reset=false
```

软重置速度更快，但在环境完成稳定步骤之后与硬重置并非逐位一致，因此相机观测（observation）和策略（policy）结果可能会有细微差异。复现基准结果时请使用硬重置。

### 策略输入与输出[[policy-inputs-and-outputs]]

**观测**（observation）：

- `observation.state`——8 维本体感知特征（末端执行器位置、轴角朝向、夹爪 qpos）
- `observation.images.image`——主相机视图（`agentview_image`），HWC uint8
- `observation.images.image2`——腕部相机视图（`robot0_eye_in_hand_image`），HWC uint8

**动作**（action）：

- `Box(-1, 1, shape=(7,))` 中的连续控制——6 维末端执行器增量 + 1 维夹爪

### 推荐的评估片段数[[recommended-evaluation-episodes]]

为保证基准测试可复现，请在全部四个标准套件（Spatial、Object、Goal、Long）上使用**每个任务 10 个片段**。这样总共得到 400 个片段，与已发表结果所用的方案一致。

## 训练[[training]]

### 数据集[[dataset]]

LIBERO-plus 的 LeRobot 格式训练数据集位于：

- [lerobot/libero_plus](https://huggingface.co/datasets/lerobot/libero_plus)

### 训练命令示例[[example-training-command]]

```bash
lerobot-train \
    --policy.type=smolvla \
    --policy.repo_id=${HF_USER}/smolvla_libero_plus \
    --policy.load_vlm_weights=true \
    --dataset.repo_id=lerobot/libero_plus \
    --env.type=libero_plus \
    --env.task=libero_spatial \
    --output_dir=./outputs/ \
    --steps=100000 \
    --batch_size=4 \
    --eval.batch_size=1 \
    --eval.n_episodes=1 \
    --env_eval_freq=1000
```

## 与 LIBERO 的关系[[relationship-to-libero]]

LIBERO-plus 是 LIBERO 的即插即用扩展：

- 相同的 Python gym 接口（`LiberoEnv`、`LiberoProcessorStep`）
- 相同的相机名称以及观测/动作格式
- 相同的任务套件名称
- 安装后使用相同的 `libero` Python 包名（GitHub 仓库不同）

如需使用原始的 LIBERO 基准，请参阅 [LIBERO](./libero) 并使用 `--env.type=libero`。
