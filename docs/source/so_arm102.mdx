# SO-ARM 102

SO-ARM 102 is an open-source leader-follower arm kit by [Robonine](https://robonine.com). Each arm has five arm joints and a sixth servo for the follower's parallel gripper or the leader's trigger. This guide covers sourcing, printing, motor placement, assembly, and the requirements for using the kit with LeRobot.

## Source the parts

Use the [bill of materials](https://github.com/roboninecom/SO-ARM-102/blob/a62866a6d65efa4be7fd421e318ce8e649ac806a/docs/bom.md) for exact part variants and fasteners. Quantities below cover one follower and one leader:

| Component                               | Quantity | Use                                                |
| --------------------------------------- | -------- | -------------------------------------------------- |
| Feetech STS3215                         | 8        | Six leader joints; follower wrist roll and gripper |
| Feetech STS3235                         | 2        | Follower base rotation and wrist flex              |
| Feetech STS3250                         | 2        | Follower shoulder lift and elbow flex              |
| Waveshare Bus Servo Driver HAT          | 1        | Follower controller                                |
| Waveshare Bus Servo Adapter             | 1        | Leader controller                                  |
| 12 V supply / 5 V supply                | 1 each   | Follower / leader respectively                     |
| USB-C data cable                        | 2        | One per controller                                 |
| USB camera                              | 1        | Follower wrist camera; check holder dimensions     |
| 6812 bearing                            | 2        | One base bearing per arm                           |
| MF106ZZ bearing                         | 2        | Parallel gripper                                   |
| Guide rod, diameter 6 mm, length 125 mm | 2        | Parallel gripper                                   |
| Table clamp                             | 4        | Two per base                                       |

Collect the printed parts, servo horns, servo cables, and fasteners listed in the BOM. You need 1.5 mm and 2 mm hex keys. Keep the 5 V leader supply separate from the 12 V follower supply and check each controller's connector and polarity.

## Print the parts

Download the [STL files](https://github.com/roboninecom/SO-ARM-102/tree/a62866a6d65efa4be7fd421e318ce8e649ac806a/models/stl), or use the [3MF projects](https://github.com/roboninecom/SO-ARM-102/tree/a62866a6d65efa4be7fd421e318ce8e649ac806a/models/3mf) with saved orientations and supports. Editable STEP sources are in the [models repository](https://github.com/roboninecom/SO-ARM-102/tree/a62866a6d65efa4be7fd421e318ce8e649ac806a/models/step).

1. Print the quantities in the [printing guide](https://github.com/roboninecom/SO-ARM-102/blob/a62866a6d65efa4be7fd421e318ce8e649ac806a/docs/printing.md). The common-part quantities already cover **both arms**; follower and leader folders contain their separate end effectors and board cases.
2. Use PET-CF for the follower links, base, and servo holders. PETG or PET-CF is specified for gripper clamps, covers, and the leader handle and trigger. The prototype used Fiberon PET-CF17.
3. Open 3MF files as projects in Bambu Studio, select your printer and filament, and inspect supports before slicing. The saved layouts use a 256 x 256 mm bed; individual parts fit a 180 x 180 mm bed, but smaller printers need rearranged plates.
4. Print each of the three projects once, plus **one extra cable snap**: the projects contain two, while the part list calls for three.
5. Remove supports and check bearing seats, screw access, and rod fit before assembly. The guide specifies 100% infill for the gripper gear and racks. Check its separate test-arm settings rather than assuming that every saved 3MF profile matches them.

## Install LeRobot

Follow the [Installation Guide](./installation), then install Feetech support from the LeRobot checkout:

```bash
pip install -e ".[feetech]"
```

Connect the USB adapters and identify each port separately:

```bash
lerobot-find-port
```

Label the ports as leader and follower. Reconnect the adapter requested by the tool to identify it; port names depend on the operating system. Installing this extra and finding ports do not add a SO-ARM 102 driver.

## Configure the motors

Set IDs **before installing the servos in the arms**. Each arm has its own bus, with IDs 1-6; the two arms must use separate adapters. Record the servo model and ID for each joint:

| ID  | LeRobot joint name             | Follower servo                     | Leader servo                  |
| --- | ------------------------------ | ---------------------------------- | ----------------------------- |
| 1   | `shoulder_pan` / base rotation | ST-3235-C001 (STS3235)             | ST-3215-C044 (STS3215), 1:191 |
| 2   | `shoulder_lift`                | ST-3250-C001 (STS3250)             | ST-3215-C044 (STS3215), 1:191 |
| 3   | `elbow_flex`                   | ST-3250-C001 (STS3250)             | ST-3215-C044 (STS3215), 1:191 |
| 4   | `wrist_flex`                   | ST-3235-C001 (STS3235)             | ST-3215-C044 (STS3215), 1:191 |
| 5   | `wrist_roll`                   | ST-3215-C018 (STS3215), 1:345      | ST-3215-C044 (STS3215), 1:191 |
| 6   | `gripper` / leader trigger     | STS3215, 1:191; full SKU pending\* | ST-3215-C044 (STS3215), 1:191 |

Full manufacturer designations: [ST-3235-C001](https://www.feetechrc.com/12v-30kg-metal-shell-metal-tooth-iron-core-motor-magnetic-coding-double-shaft-ttl-series-steering-gear), [ST-3250-C001](https://www.feetechrc.com/562636), [ST-3215-C018, 12 V, 1:345 datasheet](https://www.feetechrc.com/Data/feetechrc/upload/file/20240507/6385067068652648096680943.pdf), and [ST-3215-C044, 1:191 datasheet](https://files.seeedstudio.com/products/Feetech/101090141_Feetech_ST-3215-C044_Datasheet.pdf). All six leader motors use 1:191 gearing; do not substitute the SO-101 leader's mixed gear-ratio layout.

\*The follower gripper is specified as STS3215 with 1:191 gearing. The standard catalog variant with that ratio is **ST-3215-C044**, rated for **5–8.4 V**, not the follower's 12 V bus. The exact full SKU and power arrangement of the kit's gripper are not yet confirmed. A 12 V motor fitted with a different gearbox must be identified as a modified variant; do not label it C044 solely from its gear ratio or substitute C018's 1:345 gearing in this table.

<Tip warning={true}>
  Before powering the follower, confirm the gripper's actual voltage rating and
  its power arrangement. A standard ST-3215-C044 must not be connected to the 12
  V follower supply. Torque or current limits in software do not change its
  permitted supply voltage.
</Tip>

Robonine links its ID-setting and calibration tools at [lab.robonine.com](https://lab.robonine.com). Follow the tool's hardware instructions, connect only the servo being assigned an ID, and confirm the ID before connecting the next servo. Record the configured bus baud rate for the future driver; do not assume factory IDs are unique.

## Step-by-step assembly

The [illustrated assembly guide](https://github.com/roboninecom/SO-ARM-102/blob/a62866a6d65efa4be7fd421e318ce8e649ac806a/docs/assembly-guide.md) and [A5 assembly booklet, v0.6](https://github.com/roboninecom/SO-ARM-102/blob/a62866a6d65efa4be7fd421e318ce8e649ac806a/docs/SO-ARM102_assembly_A5_v0.6.pdf) provide full-size diagrams. Read two steps ahead before tightening: some M2 screws become difficult to reach after adjacent parts are installed.

### 1. Mount the servo horns

Fit one horn to servo ID 1 using an M3 x 6 screw. Fit horns on both sides of IDs 2, 3, and 4; use the horn screws supplied with the servos. If using optional leader O-rings, fit them between the servo and horn now, keeping them clear of the servo shell so they do not jam.

### 6. Mount and connect the arms

1. Fix each base to the table with two clamps.
2. Check wiring and cable slack with power disconnected.
3. After confirming the gripper variant and power arrangement above, connect the follower HAT to **12 V** and the leader adapter to **5 V**, checking polarity and connector compatibility.
4. Connect both controllers to the computer with USB-C data cables and identify their ports.
5. Complete the compatibility and calibration checks below before enabling follower motion.

## LeRobot compatibility check

| STS3215              | The [Feetech tables](https://github.com/huggingface/lerobot/blob/c441ebb785b7a1008203b85a241e610bec0a0711/src/lerobot/motors/feetech/tables.py) include its control table, resolution, protocol, and model number (777).                                                                                                                                                             | Motor-level support exists; SO-ARM 102 calibration still requires hardware validation.                                                                 |
| STS3250              | The same tables include support with model number 2825.                                                                                                                                                                                                                                                                                                                              | It must be declared as `sts3250`, rather than `sts3215`, at follower joints 2 and 3.                                                                   |
| STS3235              | No `sts3235` entry exists in those tables.                                                                                                                                                                                                                                                                                                                                           | Its reported model number, register layout, protocol, resolution, and encoding must be established before adding support.                              |

| Leader               | Its six STS3215 servos match the models in the [SO-101 leader mapping](https://github.com/huggingface/lerobot/blob/c441ebb785b7a1008203b85a241e610bec0a0711/src/lerobot/teleoperators/so_leader/so_leader.py).                                                                                                                                                                       | This is a candidate for reuse, but the handle, trigger range, joint limits, and direction still need physical validation.                              |

### STS3235 support accompanying this guide

The accompanying Feetech table changes register `sts3235` with model number **2057**, the STS control table, 4096-count resolution, STS baud rates and sign-magnitude encodings, and protocol version 0. FEETECH's [FD1.9.8.5 model catalog](https://gitee.com/ftservo/fddebug/tree/179d6e8c2db40e82e57aa56e8679db855c2ed605) lists `9,8,8,0,STS3235` in the archive's `ft_setup_bat/setup_en.log`; the model bytes at addresses 3 and 4 give `9 + (8 << 8) = 2057`. The same catalog identifies STS3215 as 777 and STS3250 as 2825.

Mock-based checks exercise mixed-model identification, rejection of incorrect or missing motors, homing-offset encoding, and rejection of an incompatible protocol. They do not validate motion or firmware behavior on physical STS3235 servos.

There is no dedicated upstream `so_arm102` robot type at the checked revision. The follower still needs its per-joint mapping even with all three servo models registered. The hardware guide's reference to the SO-101 workflow does not establish compatibility with this upstream version. Integration is tracked in [issue #4868](https://github.com/huggingface/lerobot/issues/4868).

Use [Bring Your Own Hardware](./integrate_hardware) for the robot and teleoperator interfaces. A separately maintained integration can use the [third-party plugin mechanism](./third_party_robots); installing the hardware files alone does not register a CLI type.

## Calibrate and validate the integration

Once a driver identifies all six follower motors with the correct model mapping, validate both arms on the actual hardware. Keep separate robot IDs and calibration files for the leader and follower; do not reuse SO-101 calibration values simply because the joint names match.

### Calibration

1. Confirm all IDs, model numbers, firmware versions, and baud rates before enabling torque. Record the LeRobot revision and any integration patches.
2. Follow the driver's torque-disabled calibration procedure. Move each arm to its specified reference pose and measure the usable range of every joint without forcing mechanical stops or pulling cables.
3. Validate wrist-roll limits against the actual cable routing. The SO-101 implementation treats wrist roll as a full-range motor; that assumption needs checking on this assembly.
4. Measure the leader trigger and follower gripper ranges separately. Confirm that opening the trigger opens the parallel gripper and that both endpoints stay within its mechanical travel.
5. Save and reload calibration, then compare leader and follower position values at matching poses before teleoperation.

The SO-101 calibration command is intentionally not prescribed here: the follower's model mapping and STS3235 support must be resolved first. Robonine's lab tools are an alternative hardware workflow, not evidence that upstream LeRobot calibration has passed.

### Teleoperation, recording, and policy deployment

After calibration, validate these stages in order using the integration's documented robot and teleoperator types:

| Stage             | Required hardware check                                                                                                                                                 |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Teleoperation     | Start with small movements and an empty gripper. Verify all joint directions, limits, leader-to-follower mapping, and stop/disconnect behavior.                         |
| Camera            | Verify wrist-camera capture, camera name, resolution, frame rate, and cable clearance through the working range.                                                        |
| Recording         | Record a short episode containing joint states, actions, and camera frames; replay the dataset to confirm feature names, timing, and gripper values.                    |
| Policy deployment | Use a policy compatible with the recorded features, joint normalization, and camera configuration. Validate its actions on this hardware before evaluating a full task. |

For the general dataset and training workflow, see [Getting started with real-world robots](./il_robots). A shared six-joint layout alone does not guarantee that a policy trained on another arm transfers to SO-ARM 102's geometry and gripper.

An end-to-end SO-ARM 102 hardware validation report is not available for this upstream revision. A reproducible report should include the hardware revision, servo IDs/model numbers/firmware, driver version, calibration results, exact commands, a teleoperation video, and a sample recorded episode. Until these checks pass, this page documents assembly and integration requirements rather than verified native support.
