# OpenGalaxea G0.5

G0.5 is a Qwen3.5-2B Vision-Language-Action model from Galaxea that generates
chain-of-thought text and robot actions in one stream: an optional subtask (and
bounding box) reasoning phase (System 2), then actions from a flow-matching head or
discrete ActionCodec tokens (System 1). See the
[G0.5 guide](https://huggingface.co/docs/lerobot/g05) for training and inference.

The code and checkpoints are under the
