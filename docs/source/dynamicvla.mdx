# DynamicVLA

DynamicVLA enables open-ended dynamic object manipulation by pairing a compact 0.4B VLM with low-latency Continuous Inference and Latent-aware Action Streaming, evaluated at scale through the new DOM benchmark in both simulation and the real world.

GitHub: https://github.com/hzxie/DynamicVLA
Project Page: https://haozhexie.com/project/dynamic-vla
Spotlight Video: https://www.youtube.com/watch?v=NmJnHcI04_Q

![Teaser](https://github.com/user-attachments/assets/ffc2071a-c4b8-4ebf-9a41-870de65bb3da)

## Set Up Your Environment

1. Install LeRobot by following our [Installation Guide](./installation).
2. Install DynamicVLA dependencies by running:

   ```bash
   pip install -e ".[dynamicvla]"
   ```

## Usage

Select DynamicVLA with `--policy.type=dynamicvla` (or load a trained checkpoint with `--policy.path`).

## Training

```bash
lerobot-train \
  --policy.type dynamicvla \
  --policy.repo_id hzxie/dynamic-vla \
  --dataset.repo_id hzxie/DOM
```

## LIBERO

[hzxie/dynamic-vla-LIBERO](https://huggingface.co/hzxie/dynamic-vla-LIBERO) is fine-tuned on [HuggingFaceVLA/libero](https://huggingface.co/datasets/HuggingFaceVLA/libero) (all four suites) from the DOM-pretrained model, for 40k steps with batch size 72 (3 GPUs × 24) and image augmentation. LIBERO actions are already relative end-effector commands, so train with `--policy.use_delta_action=false`.

Success rates (10 tasks per suite, 50 episodes per task):

| LIBERO-Spatial | LIBERO-Object | LIBERO-Goal | LIBERO-10 | Average  |
| :------------: | :-----------: | :---------: | :-------: | :------: |
|      96.6      |     98.4      |    93.4     |   93.6    | **95.5** |

To reproduce the evaluation (repeat for `libero_object`, `libero_goal` and `libero_10`):

```bash
lerobot-eval \
  --policy.path=hzxie/dynamic-vla-LIBERO \
  --env.type=libero \
  --env.task=libero_spatial \
  --eval.batch_size=10 \
  --eval.n_episodes=50
```
