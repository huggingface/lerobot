# Third-party reliability reporters

LeRobot evaluation outputs can be analyzed by independent tools without changing LeRobot itself.
Run `lerobot-eval` for each checkpoint and retain its `eval_info.json` artifacts.
External reporters read those outputs; they do not generate rollouts or replace EnvHub environments.

## Example: Arisole `arisole-eval`

[`arisole-eval`](https://pypi.org/project/arisole-eval/) is an independently maintained,
Apache-2.0-licensed command-line reporter developed by
[Arisole](https://www.arisole.com/developers/lerobot).
This example is **not an official LeRobot or Hugging Face integration, partnership, or endorsement**.

Install the published package and compare two completed evaluation runs:

```bash
pip install "arisole-eval>=0.1.4"

# Both directories must contain LeRobot evaluation artifacts.
arisole evaluate --baseline ./runs/policy-v1 --candidate ./runs/policy-v2 --out result.json
arisole report result.json
```

The reporter runs locally without an Arisole API key; optional cloud upload is separate.
It supports common `eval_info.json` layouts, including per-episode and multi-task results.
For paired regression analysis, shared seeds alone do not establish comparable labeled episodes.
Missing labels or insufficient comparable evidence must not be interpreted as a pass.

See the [Arisole developer documentation](https://www.arisole.com/developers/lerobot)
for reporter-specific behavior and configuration.
