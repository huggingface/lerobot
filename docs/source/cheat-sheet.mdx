# Cheat sheet

Every command from the [tutorial](./il_robots), in order, for an SO-101. The IDs (`my_follower`, `my_leader`) and the dataset and policy names are the tutorial's, so the commands work one after another. Each section links to the tutorial step that explains it.

> [!TIP]
> **Another robot?** Replace `so101_follower`, `so101_leader` and the ports with your robot's values from [Your robot's settings](./setup_your_robot#your-robots-settings). The tutorial pages show the same commands for other robots, in their **Other robots** tab.

## Install and log in[[setup-and-installation]]

```bash
pip install 'lerobot[core_scripts,training,feetech]'
```

Log in to the Hugging Face Hub, and save your user name in `HF_USER` for the commands below:

```bash
hf auth login
HF_USER=$(NO_COLOR=1 hf auth whoami | awk -F': *' 'NR==1 {print $2}')
```

Details: [Install LeRobot](./installation).

## 1. Find the ports and calibrate[[calibration]]

Find the port of each arm (the command asks you to unplug its USB cable), then, on Linux, give yourself access to the ports:

```bash
lerobot-find-port
sudo chmod 666 /dev/ttyACM0 /dev/ttyACM1
```

Calibrate both arms, one after the other:

```bash
lerobot-calibrate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=my_follower
```

```bash
lerobot-calibrate \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyACM1 \
    --teleop.id=my_leader
```

Every later command uses the same IDs: that's how LeRobot finds the calibration. Details: [1. Set up your robot](./setup_your_robot).

## 2. Teleoperate and add cameras[[teleoperation]]

Find your cameras (it saves a test image from each one in `outputs/captured_images`):

```bash
lerobot-find-cameras opencv
```

Teleoperate with two cameras, and watch their images:

```bash
lerobot-teleoperate \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=my_follower \
    --robot.cameras="{ top: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}, wrist: {type: opencv, index_or_path: 1, width: 640, height: 480, fps: 30}}" \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyACM1 \
    --teleop.id=my_leader \
    --display_data=true
```

Details: [2. Teleoperate and add cameras](./teleoperate).

## 3. Record a dataset[[recording-a-dataset]]

```bash
lerobot-record \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=my_follower \
    --robot.cameras="{ top: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}, wrist: {type: opencv, index_or_path: 1, width: 640, height: 480, fps: 30}}" \
    --teleop.type=so101_leader \
    --teleop.port=/dev/ttyACM1 \
    --teleop.id=my_leader \
    --display_data=true \
    --dataset.repo_id=${HF_USER}/my_first_dataset \
    --dataset.single_task="Pick up the cube and put it in the box" \
    --dataset.num_episodes=50 \
    --dataset.episode_time_s=30 \
    --dataset.reset_time_s=10 \
    --dataset.streaming_encoding=true
```

| Key                            | What it does                                            |
| ------------------------------ | ------------------------------------------------------- |
| <kbd>→</kbd> or <kbd>n</kbd>   | End the current episode (or reset) early and move on.   |
| <kbd>←</kbd> or <kbd>r</kbd>   | Throw away the current episode and record it again.     |
| <kbd>Esc</kbd> or <kbd>q</kbd> | Stop recording, save the videos and upload the dataset. |

> [!WARNING]
> `lerobot-record` adds the date and time to the dataset's name: `${HF_USER}/my_first_dataset` is saved as `${HF_USER}/my_first_dataset_YYYYMMDD_HHMMSS`. Find the full name with `ls ~/.cache/huggingface/lerobot/${HF_USER}`, or add `--dataset.no_stamp=true` to keep the exact name.

**Add more episodes** to the same dataset: run the command again with the full name in `--dataset.repo_id`, `--resume=true`, and `--dataset.num_episodes` set to the number of episodes to add.

Details: [3. Record a dataset](./record_dataset).

### Recording depth

Intel RealSense cameras (`type: intelrealsense`) record a depth stream when you set `use_depth: true`. Depth is quantized to 12-bit codes and stored as its own video.

```bash
lerobot-record \
    ... \
    --robot.cameras="{ head: {type: intelrealsense, serial_number_or_name: \"0123456789\", width: 640, height: 480, fps: 30, use_depth: true} }" \
    --dataset.repo_id=${HF_USER}/my_depth_dataset \
    --dataset.single_task="Pick up the cube and put it in the box" \
    --dataset.depth_encoder.depth_min=0.01 \
    --dataset.depth_encoder.depth_max=10.0 \
    --dataset.depth_encoder.shift=0.0 \
    --dataset.depth_encoder.use_log=true
```

### Video encoding parameters

Color and depth videos are encoded separately, with the `--dataset.rgb_encoder.*` and `--dataset.depth_encoder.*` options. See [Video size and quality settings](./video_encoding_parameters).

```bash
lerobot-record \
    ... \
    --dataset.rgb_encoder.vcodec=h264 \
    --dataset.rgb_encoder.pix_fmt=yuv420p \
    --dataset.rgb_encoder.crf=23 \
    --dataset.depth_encoder.vcodec=hevc \
    --dataset.depth_encoder.extra_options='{"x265-params": "lossless=1"}'
```

## 4. Check your data

Open an episode in the Dataset Visualizer (this prints its address):

```bash
echo "https://huggingface.co/spaces/lerobot/visualize_dataset?path=/${HF_USER}/my_first_dataset_YYYYMMDD_HHMMSS/episode_0"
```

Replay an episode on the robot:

```bash
lerobot-replay \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=my_follower \
    --dataset.repo_id=${HF_USER}/my_first_dataset_YYYYMMDD_HHMMSS \
    --dataset.episode=0
```

Save a copy of the dataset without the bad episodes:

```bash
lerobot-edit-dataset \
    --repo_id ${HF_USER}/my_first_dataset_YYYYMMDD_HHMMSS \
    --new_repo_id ${HF_USER}/my_first_dataset_clean \
    --operation.type delete_episodes \
    --operation.episode_indices "[3, 17, 41]" \
    --push_to_hub true
```

Details: [4. Check your data](./check_dataset).

## 5. Train a policy[[training]]

Train ACT on your computer's GPU (`--policy.device=mps` on a Mac):

```bash
lerobot-train \
    --dataset.repo_id=${HF_USER}/my_first_dataset_clean \
    --policy.type=act \
    --policy.device=cuda \
    --policy.repo_id=${HF_USER}/my_first_policy \
    --steps=30000 \
    --save_freq=10000 \
    --output_dir=outputs/train/my_first_policy \
    --job_name=my_first_policy \
    --trackio.enable=true
```

Or on a rented GPU with [Hugging Face Jobs](https://huggingface.co/docs/hub/jobs), billed per second (`hf jobs hardware` lists the GPUs and prices):

```bash
lerobot-train \
    --dataset.repo_id=${HF_USER}/my_first_dataset_clean \
    --policy.type=act \
    --policy.repo_id=${HF_USER}/my_first_policy \
    --steps=30000 \
    --save_freq=10000 \
    --job.target=a10g-small
```

Watch the training curves in your browser:

```bash
trackio show --project lerobot
```

Resume a stopped run from its last checkpoint:

```bash
lerobot-train \
    --config_path=outputs/train/my_first_policy/checkpoints/last/pretrained_model/train_config.json \
    --resume=true
```

**Fine-tune a pretrained policy** instead of training one from scratch: replace `--policy.type` with `--policy.path`. SmolVLA, for example, calls its cameras `camera1` and `camera2`, so map your camera names to them with `--rename_map` (see [Match camera names to a pretrained policy](./rename_map)):

```bash
lerobot-train \
    --dataset.repo_id=${HF_USER}/my_first_dataset_clean \
    --policy.path=lerobot/smolvla_base \
    --policy.device=cuda \
    --policy.repo_id=${HF_USER}/my_smolvla \
    --rename_map='{"observation.images.top": "observation.images.camera1", "observation.images.wrist": "observation.images.camera2"}' \
    --batch_size=64 \
    --steps=20000 \
    --output_dir=outputs/train/my_smolvla \
    --job_name=my_smolvla
```

Details: [5. Train a policy](./train_policy), [Choose a policy](./policies), [Which GPU do I need?](./hardware_guide).

## 6. Run it on your robot[[inference]]

Run the policy for 60 seconds:

```bash
lerobot-rollout \
    --strategy.type=base \
    --policy.path=${HF_USER}/my_first_policy \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=my_follower \
    --robot.cameras="{ top: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}, wrist: {type: opencv, index_or_path: 1, width: 640, height: 480, fps: 30}}" \
    --task="Pick up the cube and put it in the box" \
    --duration=60
```

Measure its success rate over 10 episodes, and record them:

```bash
lerobot-rollout \
    --strategy.type=episodic \
    --policy.path=${HF_USER}/my_first_policy \
    --robot.type=so101_follower \
    --robot.port=/dev/ttyACM0 \
    --robot.id=my_follower \
    --robot.cameras="{ top: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}, wrist: {type: opencv, index_or_path: 1, width: 640, height: 480, fps: 30}}" \
    --dataset.repo_id=${HF_USER}/rollout_my_first_policy \
    --dataset.single_task="Pick up the cube and put it in the box" \
    --dataset.num_episodes=10 \
    --dataset.episode_time_s=30 \
    --dataset.reset_time_s=10
```

> [!TIP]
> LeRobot 0.5 and older have no `lerobot-rollout`: run policies with `lerobot-record` instead, as in the [0.5 docs](https://huggingface.co/docs/lerobot/v0.5.1/en/il_robots#run-inference-and-evaluate-your-policy).

Details: [6. Run it on your robot](./run_policy), and [All ways to run a policy](./inference).

## Without a robot: simulation

Evaluate a policy in a simulation, and get its success rate:

```bash
lerobot-eval \
    --policy.path=outputs/train/diffusion_pusht/checkpoints/last/pretrained_model \
    --policy.device=cuda \
    --env.type=pusht \
    --eval.n_episodes=100 \
    --output_dir=outputs/eval/diffusion_pusht
```

Details: [Train and evaluate in simulation](./train_in_sim).
