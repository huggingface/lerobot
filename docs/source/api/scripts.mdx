# Scripts

`src/lerobot/scripts/` holds the CLI entry points mapped in `pyproject.toml`'s `[project.scripts]`
(`lerobot-train`, `lerobot-record`, `lerobot-eval`, ...). This page documents each command's configuration
— every field below is settable as a `--flag` on the command line. For setup, recording, and training
walkthroughs, start with [`AGENT_GUIDE.md`](https://github.com/huggingface/lerobot/blob/main/AGENT_GUIDE.md).
