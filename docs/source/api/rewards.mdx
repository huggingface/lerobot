# Reward Models

Every reward model in LeRobot implements [`PreTrainedRewardModel`]: `compute_reward` returns a scalar
reward signal for a batch of observations. Reward models are used for automated evaluation, RL training
(see [Reinforcement Learning](./rl)), and RA-BC (Reward-Aligned Behavior Cloning) sample weighting.

Each zero-shot / pretrained reward model has its own guide — [SARM](../sarm), [ROBOMETER](../robometer),
[TOPReward](../topreward).
