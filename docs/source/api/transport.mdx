# Transport

`src/lerobot/transport/` holds the gRPC transport layer shared by `lerobot.rl` (actor/learner) and
`lerobot.async_inference`: chunked byte streaming for large payloads, (de)serialization helpers, and
channel configuration. `services_pb2.py`/`services_pb2_grpc.py` are generated by the gRPC protoc
plugin from the package's `.proto` definitions and are not part of this reference.
