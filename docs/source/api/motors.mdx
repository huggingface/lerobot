# Motors

`SerialMotorsBus` is the low-level interface to a chain of servos on a serial bus. Robots use it to read positions
and write goal positions; you rarely touch it directly unless you are adding hardware. `FeetechMotorsBus` and
`DynamixelMotorsBus` implement it. Control tables come from [rustypot](https://github.com/pollen-robotics/rustypot),
which also owns the serial port.

See [Bring Your Own Hardware](../integrate_hardware) for adding a new bus, and
[Updating Feetech Firmware](../feetech) and [Damiao Motors and CAN Bus](../damiao) for device-specific notes.
