# SOLE-R1

SOLE-R1 is a video-language reward model that predicts robot
task progress from visual observations and a natural-language goal. It reasons
over the first, previous, and current observations and generates:

```text
<think>reasoning about task progress</think><answer>progress%</answer>
```

**Paper**: [SOLE-R1: Video-Language Reasoning as the Sole Reward for On-Robot Reinforcement Learning](https://arxiv.org/abs/2603.28730)

**Project**: [philip-mit.github.io/sole-r1](https://philip-mit.github.io/sole-r1/)

**Original code**: [github.com/Philip-MIT/sole-r1-model](https://github.com/Philip-MIT/sole-r1-model)

**Checkpoint**: [Philip-MIT/SOLE-R1-8B](https://huggingface.co/Philip-MIT/SOLE-R1-8B)

## Installation

From a LeRobot source checkout:

```bash
pip install -e ".[soler1]"
```

or:

```bash
uv sync --extra soler1
```

GPU inference is strongly recommended.

## Usage

### Load the reward model directly

```python
from lerobot.rewards.soler1 import SOLER1Config, SOLER1RewardModel

cfg = SOLER1Config(
    device="cuda",
    external_image_key="observation.images.top",
    wrist_image_key="observation.images.wrist"
)
reward_model = SOLER1RewardModel(cfg)
```

### Use the reward factory

```python
from lerobot.rewards import make_reward_model, make_reward_model_config, make_reward_pre_post_processors

cfg = make_reward_model_config(
    "sole-r1",
    device="cuda",
    external_image_key="observation.images.top",
    wrist_image_key="observation.images.wrist",
)
reward_model = make_reward_model(cfg)
preprocessor, _ = make_reward_pre_post_processors(cfg)
```

### Inputs

SOLE-R1 supports an external camera, a wrist camera, or both. At least one
camera key must be configured.

LeRobot channels-first trajectories use:

```text
(T, C, H, W)
(B, T, C, H, W)
```

Channels-last `(T, H, W, C)` and `(B, T, H, W, C)` inputs are also accepted.

For every evaluated timestep, the preprocessor creates the composite expected
by SOLE-R1:

```text
first | previous | current
```

With two cameras, the external-camera row is placed above the wrist-camera
row. Each frame is resized with aspect-ratio-preserving padding to `384 × 384`.

### Compute rewards (sparse or dense)

`compute_reward(batch, dense=True)` returns progress for every original
trajectory timestep. If `downsample_to` is set, SOLE-R1 evaluates only the
sampled anchors and linearly interpolates between them.

```python
import torch

# One channels-first trajectory: (T, C, H, W).
frames = torch.randint(
    0,
    256,
    (8, 3, 224, 224),
    dtype=torch.uint8,
)

batch = preprocessor(
    {
        cfg.external_image_key: frames,
        cfg.wrist_image_key: frames,
        cfg.task_key: "pick up the red cube",
    }
)

# Sparse reward taken from last timestep
reward = reward_model.compute_reward(batch)
print(reward.shape)  # (1,)

# Dense reward for all timesteps
rewards = reward_model.compute_reward(batch, dense=True)
print(rewards.shape) # (1, 8)
```

The first sampled timestep is defined as `0%`. Later timesteps are evaluated
sequentially because the prompt for the current timestep includes the previous
predicted progress.

With the default `reward_scale=0.01`, a generated progress value of `75%`
produces a reward of `0.75`.

## Offline dataset labeling

Write a soler1_progress.parquet for RA-BC training and overlay videos:

```python
from pathlib import Path

import numpy as np
import pyarrow as pa
import pyarrow.parquet as pq
import torch
from tqdm import tqdm

from lerobot.datasets import LeRobotDataset
from lerobot.rewards import make_reward_model, make_reward_model_config, make_reward_pre_post_processors

dataset_repo_id = "lerobot/libero_10_image"
output_path = Path("soler1_progress.parquet")

cfg = make_reward_model_config(
    "sole-r1",
    device="cuda",
    external_image_key="observation.images.top",
    wrist_image_key=None,
    downsample_to=10,
)
model = make_reward_model(cfg).eval()
preprocessor, _ = make_reward_pre_post_processors(cfg)
dataset = LeRobotDataset(dataset_repo_id, download_videos=True)

all_indices = []
all_episode_indices = []
all_frame_indices = []
all_progress = []

for episode_index in tqdm(range(dataset.num_episodes)):
    episode = dataset.meta.episodes[episode_index]
    start = int(episode["dataset_from_index"])
    end = int(episode["dataset_to_index"])

    samples = [dataset[index] for index in range(start, end)]
    frames = torch.stack([sample[cfg.external_image_key] for sample in samples])

    task = samples[0].get("task")
    if not isinstance(task, str) or not task:
        raise KeyError(
            f"Episode {episode_index} does not contain a task description"
        )

    batch = preprocessor({cfg.external_image_key: frames, cfg.task_key: task,})

    with torch.no_grad():
        progress = (model.compute_reward(batch, dense=True).squeeze(0).cpu().numpy())

    for frame_index, value in enumerate(progress):
        all_indices.append(start + frame_index)
        all_episode_indices.append(episode_index)
        all_frame_indices.append(frame_index)
        all_progress.append(float(value))

table = pa.table(
    {
        "index": np.asarray(all_indices, dtype=np.int64),
        "episode_index": np.asarray(
            all_episode_indices,
            dtype=np.int64,
        ),
        "frame_index": np.asarray(all_frame_indices, dtype=np.int64),
        "progress_sparse": np.asarray(all_progress, dtype=np.float32),
    }
).replace_schema_metadata(
    {
        b"reward_model_type": b"sole-r1",
        b"model_name": cfg.model_name.encode(),
    }
)

pq.write_table(table, output_path)
print(f"Saved {len(table)} labels to {output_path}")
```

To render an overlay:

```bash
uv run examples/dataset/create_progress_videos.py \
    --repo-id lerobot/libero_10 \
    --episode 0 \
    --progress-file soler1_progress.parquet \
    --gif
```

## Success output

SOLE-R1 can return a binary trajectory-level success value:

```python
cfg = make_reward_model_config(
    "sole-r1",
    device="cuda",
    reward_output="success",
    success_threshold=0.8,
)
```

The predicted progress is scaled first, then compared with
`success_threshold`.

## Invalid generations

By default, if a completion cannot be parsed, SOLE-R1 reuses the preceding
progress value. To make malformed output an error:

```python
cfg = make_reward_model_config(
    "sole-r1",
    fallback_to_previous=False,
)
```

## Serialization

SOLE-R1 is inference-only. `save_pretrained()` stores the LeRobot
`config.json`; the underlying model remains referenced by `model_name`.

```python
reward_model.save_pretrained("soler1_config")
```

Reload it with:

```python
from lerobot.rewards.soler1 import SOLER1RewardModel

reward_model = SOLER1RewardModel.from_pretrained("soler1_config")
```

## Limitations

- The integration implements inference only.
- Predictions are autoregressive across trajectory timesteps, so a malformed or inaccurate prediction can affect later predictions.
